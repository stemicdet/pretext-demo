    Section Week 8: Limits of Integrals and Integrals of Limits (3B)

    Subsection Bounded Convergence Theorem

    Suppose that \(\{f_n\}\) is a sequence of integrable functions that converges to a limit function \(f\text{.}\) An important question with many applications is when is it true that
    \begin{equation*} \lim_{n\to \infty} \int f_n d\mu = \int f d\mu; \end{equation*}
    in other words, when are we permitted to exchange limit and integral?
    🔗
    In MTH 528 we saw that when the integral is the Riemann integral, if convergence is uniform, then we are permitted to exchange limit and integral. Can we do better with the Lebesgue Integral?
    🔗
    Example: Let \(r_n\) be a (countable) list of the rational numbers and define functions \(f_n(x)\) by
    \begin{equation*} f_n(x) = \begin{cases} \hfill 1 \amp \text{ if $x \in \{r_1, r_2, \ldots, r_n\}$} \\ \hfill 0 \hfill \amp \text{ otherwise} \end{cases} \end{equation*}
    🔗
    Each \(f_n\) is \(0\) except at a finite number of points, so it is Riemann integrable with integral \(0\text{,}\) but \(f_n\) converges pointwise to Dirichlet’s function
    \begin{equation*} f(x) = \begin{cases} \hfill 1 \amp \text{ if } \\ \hfill 0 \hfill \amp \text{ if } \end{cases} \end{equation*}
    which is not Riemann integrable. However, it is Lebesgue integrable with integral \(0\text{.}\)
    🔗
    Example: Let
    \begin{equation*} g_n(x) = \begin{cases} \hfill n \amp \text{ if $0 < x < \frac{1}{n}$} \\ \hfill 0 \hfill \amp \text{ if $x =0 $ or $x \geq \frac{1}{n}$} \end{cases} \end{equation*}
    🔗
    For each \(n\text{,}\) \(g_n(x)\) is Lebesgue integrable with integral \(1\text{;}\) however, \(\{g_n\}\) converges pointwise to \(g(x) = 0\text{,}\) which has Lebesgue integral \(0\text{,}\) so we can’t exchange limit and integral. Notice that in the first example \(|f_n(x)| \leq 1\) for all \(n\text{,}\) but in the second example \(\{g_n\}\) is unbounded.
    🔗

    Theorem 84. Bounded Convergence Theorem.

    Suppose \((X,S,\mu)\) is a measure space with \(\mu(X) < \infty\text{.}\) Suppose \(f_1, f_2, \ldots\) is a sequence of \(S\)-measurable functions from \(X \to \mathbf{R}\) that converges pointwise on \(X\) to a function \(f:X \to \mathbf{R}\text{.}\) If there exists \(c \in (0,\infty)\) such that
    \begin{equation*} |f_k(x)| \leq c \end{equation*}
    for all \(k \in \mathbf{N}\) and \(x \in X\text{,}\) then
    \begin{equation*} \lim_{k\to \infty} \int f_k d\mu = \int f d\mu. \end{equation*}
    🔗
    🔗

    Lemma 85. Bounding an Integral.

    Suppose \((X,S, \mu)\) is a measure space, \(E\) is a subset in \(S\text{,}\) and \(f:X \to [-\infty,\infty]\) is a function such that \(\int_E f d\mu\) is defined. Then
    \begin{equation*} \int_E f d\mu \leq \mu(E) \sup_E |f|. \end{equation*}
    🔗
    🔗

    Proof.

    Let \(c = \sup_E |f|\text{.}\) Then
    \begin{equation*} \int_E f d\mu \leq \int_E c d\mu = c \int_E d\mu = c \mu(E). \end{equation*}
    🔗
    🔗
    Now we can prove the Bounded Convergence Theorem
    🔗

    Proof.

    The main idea of the proof is that by Egorov’s Theorem, every convergent sequence is almost uniformly convergent and if convergence is uniform then you can interchange limit and integral.
    🔗
    Let \(\epsilon > 0\text{.}\) Then by Egorov’s Theorem there is a subset \(E \in S\) such that \(\mu(X \setminus E) < \epsilon\) and \(f_1, f_2, \ldots\) converges uniformly to \(f\) on \(E\text{.}\) Then
    \begin{align*} \left|\int f_k d\mu - \int f d\mu\right| \amp = \left| \int_{X \setminus E} f_k d\mu - \int_{X\setminus E} f d\mu + \int_E (f_k-f) d\mu \right| \\ \amp \leq \int_{X\setminus E} |f_k| d\mu + \int_{X\setminus E} |f| d\mu + \int_E |f_k -f| d\mu \\ \amp < 2c \epsilon + \mu(E) \sup_E |f_k - f|, \end{align*}
    where the last line follows from applying the lemma.
    🔗
    Since \(\{f_k\}\) converges uniformly to \(f\) on \(E\text{,}\) it follows that for large \(k\text{,}\) \(|f_k-f| < \epsilon\text{.}\) Hence for \(k\) sufficiently large,
    \begin{equation*} \left|\int f_k d\mu - \int f d\mu\right| < 2c \epsilon + \mu(E) \epsilon, \end{equation*}
    and since \(\epsilon > 0\) is arbitrary this can be made as small as possible. Thus \(\int f_k d\mu \to \int f d\mu\) as \(k \to \infty\text{.}\)
    🔗
    🔗
    🔗

    Subsection Sets of Measure Zero in Integration

    Example: Suppose that
    \begin{equation*} f_n(x) = \begin{cases} \hfill n \amp \text{ if $x \in [0,1] \cap \mathbf{Q} $} \\ \hfill \frac{x}{n} \hfill \amp \text{ if $x \in [0,1] \setminus \mathbf{Q} $} \end{cases} \end{equation*}
    🔗
    Then \(\{f_n\}\) converges pointwise to
    \begin{equation*} f(x) = \begin{cases} \hfill \infty \amp \text{ if $x \in [0,1] \cap \mathbf{Q} $} \\ \hfill 0 \hfill \amp \text{ if $x \in [0,1] \setminus \mathbf{Q} $} \end{cases} \end{equation*}
    but both \(\{f_n\}\) and \(f\) are unbounded, so we can’t use Bounded Convergence Theorem, or can we?
    🔗
    Note that \(\{f_n\}\) is bounded almost everywhere; that is, it is only unbounded on a set of measure zero and since sets of measure zero are negligible with respect to integration we can still use BCT.
    🔗
    Define a new function \(g_n(x)\) by
    \begin{equation*} g_n(x) = \begin{cases} \hfill 0 \amp \text{ if $x \in [0,1] \cap \mathbf{Q} $} \\ \hfill \frac{x}{n} \hfill \amp \text{ if $x \in [0,1] \setminus \mathbf{Q} $} \end{cases} \end{equation*}
    🔗
    Then \(\{g_n\}\) converges pointwise to \(g(x) = 0\text{.}\) Since \(\{g_n\}\) is bounded by \(1\text{,}\) we can use BCT to conclude that
    \begin{equation*} \int_0^1 g_n d\mu = \int_0^1 g d\mu = 0. \end{equation*}
    🔗
    Since
    \begin{equation*} \int_0^1 f_k d\mu = \int_0^1 g_k d\mu \text{ and } \int_0^1 f d\mu = \int_0^1 g d\mu \end{equation*}
    it follows that
    \begin{equation*} \int_0^1 f_k d\mu = \int_0^1 f d\mu = 0. \end{equation*}
    🔗
    The ideas of this example can be universally applied to theorems about integrals. In most every case, the hypotheses of a theorem about integrals can be relaxed so that the hypotheses just hold almost everywhere; that is, outside a set of measure zero. The previous example shows that the BCT still holds if the sequence of functions is bounded almost everywhere on \(X\) instead of needing to be bounded on all \(X\text{.}\)
    🔗
    🔗

    Subsection Dominated Convergence Theorem

    The BCT says that we can interchange limit and integral if the sequence of functions is uniformly bounded and the measure of the space is finite. The MCT says that we can interchange limit and integral if the functions are non-negative and increasing. The Dominated Convergence Theorem does away with these restrictions. The only requirement for the DCT is that the sequence of functions can be bounded by another integrable function.
    🔗

    Theorem 86. Dominated Convergence Theorem.

    Suppose \((X,S,\mu)\) is a measure space, \(f:X \to [-\infty,\infty]\) is \(S\)-measurable, and \(f_1, f_2, \ldots\) are \(S\)-measurable functions from \(X \to [-\infty,\infty]\) such that
    \begin{equation*} \lim_{k\to \infty} f_k(x) = f(x) \end{equation*}
    for almost every \(x \in X\text{.}\) If there exists an \(S\)-measurable function \(g:X \to [0,\infty]\) such that
    \begin{equation*} \int g d\mu < \infty \text{ and } |f_K(x)| \leq g(x) \end{equation*}
    for every \(k \in \mathbf{N}\) and almost every \(x \in X\text{,}\) then
    \begin{equation*} \lim_{k \to \infty} f_k d\mu = \int f d\mu. \end{equation*}
    🔗
    🔗
    To prove the DCT we will need the following lemma.
    🔗

    Lemma 87.

    Suppose \((X,S,\mu) \) is a measure space, \(g: X \to [0,\infty]\) is \(S\)-measurable and \(\int g d\mu < \infty\text{.}\) Then for every \(\epsilon > 0\text{,}\) there exists \(\delta > 0\) such that
    \begin{equation*} \int_B g d\mu < \epsilon \end{equation*}
    for every set \(B\) in \(S\) with \(\mu(B) < \delta\text{.}\)
    🔗
    🔗

    Proof.

    Choose \(\epsilon < 0\) and let \(h\) be a simple function such that \(0 \leq h \leq g\) and
    \begin{equation*} \int g d\mu - \int h d\mu < \frac{\epsilon}{2}. \end{equation*}
    The existence of such a function is given by the definition of the Lebesgue integral for non-negative functions. Let \(H = \sup\{h(x): x \in X\} \) and choose \(\delta > 0\) such that \(H\delta < \frac{\epsilon}{2}\text{.}\)
    🔗
    Now suppose \(B \in S\) and \(\mu(B) < \delta\text{.}\) Then
    \begin{align*} \int_B g d\mu \amp = \int_B (g-h) d\mu + \int_B h d\mu \\ \amp \leq \int (g-h) d\mu + \int_B H d\mu \\ \amp < \frac{\epsilon}{2} + H \mu(B) \\ \amp < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon. \end{align*}
    🔗
    🔗
    Now we can prove the Dominated Convergence Theorem.
    🔗

    Proof.

    Suppose \(g:X \to [0,\infty]\) satisfies the hypotheses of the theorem. If \(E\in S\text{,}\) then
    \begin{align*} \left| \int f_k d\mu - \int fd\mu \right| \amp = \left| \int_{X\setminus E} f_k d\mu - \int_{X\setminus E} fd\mu + \int_E f_k d\mu - \int_E fd\mu \right|\\ \amp \leq \left| \int_{X\setminus E} f_k d\mu \right|+ \left|\int_{X\setminus E} fd\mu \right| + \left| \int_E f_k d\mu - \int_E fd\mu \right|\\ \amp \leq 2 \left| \int_{X\setminus E} g d\mu \right|+ \left| \int_E f_k d\mu - \int_E fd\mu \right| \end{align*}
    🔗
    Suppose that \(\mu(X) < \infty\text{.}\) Then by the first lemma, there exists \(\delta > 0\) such that
    \begin{equation*} \int_B g d\mu < \epsilon \end{equation*}
    for every set \(B \in S\) such that \(\mu(B) < \delta\text{.}\)
    🔗
    By Egorov’s Theorem, there exists a set \(E \in S\) such that \(\mu(X\setminus E) < \delta\) and the sequence \(f_1, f_2, \ldots\) converges uniformly to \(f\) on \(E\text{.}\) Thus for \(k\) sufficiently large,
    \begin{align*} \left| \int f_k d\mu - \int fd\mu \right| \amp \leq 2 \left| \int_{X\setminus E} g d\mu \right|+ \left| \int_E f_k d\mu - \int_E fd\mu \right| \\ \amp \leq 2 \epsilon + \int_E (f_k - f) d\mu\\ \amp \leq 2 \epsilon + \mu(E) \epsilon \end{align*}
    🔗
    Since \(\epsilon > 0\) was arbitrarily chosen, this can be made as small as desired and hence
    \begin{equation*} \lim_{k\to \infty} \int f_k d\mu = \int f d\mu. \end{equation*}
    🔗
    🔗
    🔗

    Subsection Riemann Integral and Lebesgue Integral

    In MTH 528 we discussed Lebesgue’s theorem, which stated that a function is Riemann integrable if and only if its discontinuities form a set of measure zero. We now have the tools to prove this result.
    🔗

    Theorem 88. Lebesgue’s Theorem.

    Suppose \(a < b\) and \(f: [a,b] \to \mathbf{R}\) is a bounded function. Then \(f\) is Riemann integrable if and only if
    \begin{equation*} |\{x\in [a,b]: f \text{ is not continuous at } x\}| = 0 \end{equation*}
    Furthermore if \(f\) is Riemann integrable and \(\lambda\) denotes Lebesgue measure on \(\mathbf{R}\) then \(f\) is Lebesgue measurable and
    \begin{equation*} \int_a^b f(x) dx = \int_{[a,b]} f d\lambda. \end{equation*}
    🔗
    🔗

    Proof.

    For this proof we will make use of the fact that the Riemann integral and the Darboux integral are equivalent so that we can use the definition of the Darboux integral. Choose \(n \in \mathbf{N}\) and let \(P_n\) be the partition that divides \([a,b]\) into \(2^n\) subintervals of equal size. Let \(I_1, I_2, \ldots I_{2^n}\) be the corresponding subintervals and note that each has length \(\frac{b-a}{2^n}\text{.}\)
    🔗
    Now define
    \begin{equation*} g_n = \sum_{j=1}^{2^n} (\inf_{I_j} f) \chi_{I_j} \quad \text{ and } \quad h_n = \sum_{j=1}^{2^n} (\sup_{I_j} f) \chi_{I_j} \end{equation*}
    This allows us to define the Lower and Upper sums in terms of integrals.
    \begin{equation*} L(f,P_n) = \int_{[a,b]} g_n d \lambda \quad \text{ and } \quad U(f,P_n) = \int_{[a,b]} h_n d \lambda \end{equation*}
    🔗
    There is an issue with points on the boundary of two subintervals, so we will need to modify our definitions of \(g_n\) and \(h_n\) slightly. At points on a boundary of two subintervals, define \(g_n\) to be the infimum over both subintervals and define \(h_n\) to be the supremum over both subintervals. Since this only changes the values of \(g_n\) and \(h_n\) at a finite number of points, the lower and upper sums are still defined by the exact same integrals.
    🔗
    Taking the limit as \(n\to \infty\) is makes the partitions finer. Thus \(g_1 \leq g_2 \leq \ldots\) is an increasing sequence of functions and \(h_1 \geq h_2 \geq \ldots\) is a decreasing sequence of functions on \([a,b]\text{.}\) Define a lower function \(f^L\) and upper function \(f^U: [a,b] \to \mathbf{R}\) by
    \begin{equation*} f^L(x) = \lim_{n\to \infty} g_n(x) \quad \text{ and } \quad f^U(x) = \lim_{n\to \infty} h_n(x). \end{equation*}
    🔗
    Since these sequences are bounded we can apply the BCT or DCT to interchange limit and integral. Hence
    \begin{align*} \int_{[a,b]} f^L d \lambda \amp = \int_{[a,b]} \lim_{n\to \infty} g_n d \lambda \\ \amp = \lim_{n\to \infty} \int_{[a,b]} g_n d \lambda \\ \amp = \lim_{n\to \infty} L(f, P_n) = L(f). \end{align*}
    🔗
    Likewise
    \begin{equation*} \int_{[a,b]} f^U d \lambda = U(f). \end{equation*}
    🔗
    The function \(f\) is Riemann integrable if and only if \(U(f) - L(F) = 0\text{.}\) This means that \(f\) is Riemann integrable if and only if
    \begin{equation*} \int_{[a,b]} f^U - f^L d\lambda = 0. \end{equation*}
    🔗
    Since \(f^L \leq f^U\) the only way that this integral is \(0\) is for \(f^L = f^U\) almost everywhere. In other words, the integral is \(0\) if and only if
    \begin{equation*} |\{x \in [a,b]: f^L(x) \neq f^U(x)\}| = 0 \end{equation*}
    🔗
    It follows from how \(f^L\) and \(f^U\) are defined that
    \begin{equation*} \{x \in [a,b]: f^L(x) \neq f^U(x)\} = \{x \in [a,b]: f \text{ is discontinuous at } x\} \end{equation*}
    Thus \(f\) is Riemann integrable if and only if its discontinuities form a set of measure zero.
    🔗
    🔗
    Since every Riemann integrable function is Lebesgue integrable, we no longer need to distinguish between the two types of integrals. From now on, when we use the term integrable, we understand it to mean the Lebesgue integral. This also means that in many cases we don’t need to use the definition of the Lebesgue integral when working with integrals. If we are integrating a function that is nicely integrable using the Riemann integral, we can use that instead, and likewise if we are integrating a function which has a nice antiderivative we can use the Fundamental Theorem of Calculus to integrate it.
    🔗
    🔗

    Subsection Approximation by Nice Functions

    Definition 89. Banach Space.

    A Banach space is a complete normed vector space.
    🔗
    🔗
    Informally a Banach space is a set of functions which is closed under addition, scalar multiplication, and limits, and in which there is a well defined notion of distance. Banach spaces are widely studied in functional analysis. The set of Lebesgue integrable functions on a measure space is almost, but not quite, a Banach space. We will prove some of the properties of this set.
    🔗

    Definition 90. \(||f||_1\text{,}\) \(\mathcal{L}^1(\mu)\).

    Suppose \((X,S, \mu)\) is a measure space. If \(f:X \to [-\infty,\infty]\) is \(S\)-measurable, then the \(\mathcal{L}^1\) norm of \(f\) is denoted by \(||f||_1\) and defined by
    \begin{equation*} ||f||_1 = \int |f| d\mu \end{equation*}
    🔗
    The Lebesgue space \(\mathcal{L}^1(\mu)\) is defined by
    \begin{equation*} \mathcal{L}^1(\mu) = \{f: f \text{ is a measurable function from } X \text{ to } \mathbf{R} \text{ and } ||f||_1 < \infty\}. \end{equation*}
    🔗
    🔗
    Note: Technically \(||f||_1\) is a semi-norm, not a norm, but for convenience we will call it a norm.
    🔗
    Example: Let \(\lambda\) denote Lebesgue measure on \(\mathbf{R}\text{.}\) Then \(\mathcal{L}^1(\lambda)\) is the set of functions whose Lebesgue integral over the entire real line is finite. This is typically denoted as \(\mathcal{L}^1(\mathbf{R})\text{.}\)
    🔗
    Let \(\mu\) denote the counting measure on \(\mathbf{N}\) and let \(x = (x_1, x_2, \ldots,)\) be a sequence of real numbers. (Recall that a sequence of numbers can be thought of as a function on \(\mathbf{N}\text{.}\)) Then \(||x||_1 = \displaystyle \sum_{k=1}^{\infty} |x_k|\text{.}\) In this case \(\mathcal{L}^1(\mu)\) is denoted by \(\ell^1\text{.}\) In other words \(\ell^1\) is the set of sequences \((x_1, x_2, \ldots)\) of real numbers such that \(\displaystyle \sum_{k=1}^{\infty} |x_k| < \infty\text{.}\)
    🔗

    Theorem 91. Properties of the \(\mathcal{L}^1\) Norm.

    Suppose \((X,S,\mu)\) is a measure space and \(f,g \in \mathcal{L}^1(\mu)\text{.}\) Then
    1. \(||f||_1 \geq 0\text{.}\)
      🔗
      🔗
    2. \(||f||_1 = 0\) if and only if \(f = 0\) for almost every \(x\in X\text{.}\)
      🔗
      🔗
    3. \(||cf||_1 = |c| ||f||_1\) for every \(c \in \mathbf{R}\text{.}\)
      🔗
      🔗
    4. \(||f+g||_1 \leq ||f||_1 + ||g||_1\text{.}\) (Triangle Inequality)
      🔗
      🔗
    🔗
    🔗

    Proof.

    Because \(|f| \geq 0\text{,}\) it follows that
    \begin{equation*} ||f||_1 = \int |f| d\mu \geq \int 0 d\mu = 0. \end{equation*}
    Thus (a) is proven.
    🔗
    Moreover \(||f||_1 = 0\) if and only if
    \begin{equation*} \int |f| d\mu = 0 \end{equation*}
    if and only if \(f = 0\) for almost every \(x \in X\text{.}\) Thus (b) is proved.
    🔗
    To prove (c) note that
    \begin{equation*} ||cf||_1 = \int |cf| d\mu = |c| \int |f| d\mu = |c| ||f||_1. \end{equation*}
    🔗
    Finally we prove (d).
    \begin{equation*} ||f+g||_1 = \int |f+g| d\mu \leq \int |f| d\mu + \int |g| d\mu = ||f||_1 + ||g||_1. \end{equation*}
    🔗
    🔗
    Next we will show that every function in \(\mathcal{L}^1(\mu)\) can be approximated in \(\mathcal{L}^1\) by simple functions.
    🔗

    Theorem 92. Approximation by Simple Functions.

    Suppose \(\mu\) is a measure and \(f \in \mathcal{L}^1(\mu)\text{.}\) Then for every \(\epsilon>0\) there exists a simple function \(g \in \mathcal{L}^1(\mu)\) such that
    \begin{equation*} ||f-g||_1 < \epsilon. \end{equation*}
    🔗
    🔗
    A corollary of this theorem is that given \(f \in \mathcal{L}^1(\mu)\text{,}\) there exists a sequence \(\{g_n\}\) of simple functions that converges to \(f\) in the \(\mathcal{L}^1\) norm; that is,
    \begin{equation*} ||f-g_n||_1 \to 0 \text{ as } n \to \infty. \end{equation*}
    🔗

    Proof.

    The idea of the proof is that we can approximate \(f^+\) and \(f^-\) by simple functions and we can use these to approximate \(f\text{.}\) Let \(\epsilon > 0\text{.}\) Then there exists simple functions \(g_1\) and \(g_2\) such that \(0 \leq g_1 \leq f^+\text{,}\) \(0 \leq g_2 \leq f^-\text{,}\) and
    \begin{equation*} \int (f^+-g_1) d\mu < \frac{\epsilon}{2} \quad \text{ and } \quad \int (f^- -g_2) d\mu < \frac{\epsilon}{2} \end{equation*}
    🔗
    Now let \(g = g_1 - g_2\text{.}\) Then \(g\) is a simple function and
    \begin{align*} ||f-g||_1 \amp = ||(f^+-g_1) - (f^- -g_2)||_1\\ \amp \leq \int (f^+ -g_1) d\mu + \int (f^- -g_2) d\mu \\ \amp < \epsilon \end{align*}
    as desired.
    🔗
    🔗
    It turns out that we can do even better than approximate \(\mathcal{L}^1\) functions by simple functions; we can approximate them by step functions.
    🔗

    Definition 93. Step Function.

    A step function is a function \(g: \mathbf{R}\to \mathbf{R}\) of the form
    \begin{equation*} g = a_1 \chi_{I_1} + a_2 \chi_{I_2} + \ldots + a_n \chi_{I_n} \end{equation*}
    where \(I_1\text{,}\) \(I_2\text{,}\) \ldots \(I_n\) are intervals of \(\mathbf{R}\) and \(a_1, a_2, \ldots a_n\) are nonzero real numbers.
    🔗
    🔗
    Recall that every simple function can be written in the form
    \begin{equation*} g = a_1 \chi_{E_1} + a_2 \chi_{E_2} + \ldots + a_n \chi_{E_n} \end{equation*}
    where each \(E_k = g^{-1}(c_k)\) for real number \(c_k\text{.}\)
    🔗
    The difference between a step function and a simple function is that in a simple function the sets \(E_k\) do not have to be intervals, but they do in a step function. Every step function is a simple function, but not every simple function is a step function.
    🔗

    Theorem 94. Approximation by Step Functions.

    Suppose \(f \in \mathcal{L}^1(\mathbf{R})\text{.}\) Then for every \(\epsilon > 0\text{,}\) there exists a step function \(g \in \mathcal{L}^1(\mathbf{R})\) such that \(||f-g||_1 < \epsilon\text{.}\)
    🔗
    🔗

    Proof.

    The idea of the proof is to first approximate \(f\) by simple functions and then approximate the simple functions by step functions. Let \(\epsilon > 0\text{.}\) Then there exists Lebesgue measurable sets \(A_1\text{,}\) \(A_2\text{,}\) \ldots \(A_n\) of \(\mathbf{R}\) and nonzero numbers \(a_1\text{,}\) \(a_2\text{,}\) \ldots \(a_n\) such that \(|A_k| < \infty\) for all \(k \in \{1, 2, \ldots n\}\) and
    \begin{equation*} \left \Vert f- \sum_{k=1}^n a_k \chi_{A_k} \right\Vert_1 < \epsilon. \end{equation*}
    🔗
    Now because every measurable set is almost an open set, for each \(A_k\) there exists an open set \(G_k\) such that \(A_k \subseteq G_k\) and \(|G_k \setminus A_k| < \epsilon\text{.}\) Moreover, each open subset of \(\mathbf{R}\) can be expressed as a countable union of disjoint open intervals. Thus for each \(k\) there exists a set \(E_k\) that is a finite union of disjoint open intervals such that \(E_k \subseteq G_k\) and \(|G_k \setminus E_k| < \epsilon\text{.}\)
    🔗
    Hence \(|E_k \setminus A_k| + |A_k \setminus E_k| \leq |G_k \setminus A_k| + |G_k \setminus E_k| < \epsilon+\epsilon = 2\epsilon\text{.}\) Observe that
    \begin{equation*} \chi_{A_k} - \chi_{E_k} = \begin{cases} \hfill 1 \amp \text{ if $x \in A_k \setminus E_k$} \\ \hfill 0 \hfill \amp \text{ if $x \in A_k \cap E_k$ or $x \notin A_k \cup E_k$} \\ \hfill -1 \amp \text{ if $x \in E_k \setminus A_k$} \\ \end{cases} \end{equation*}
    🔗
    Hence
    \begin{equation*} ||\chi_{A_k} - \chi_{E_k}||_1 = |E_k \setminus A_k| + |A_k \setminus E_k| < 2\epsilon. \end{equation*}
    🔗
    Thus it follows that
    \begin{align*} \left\Vert f- \sum_{k=1}^n a_k \chi_{E_k} \right\Vert_1\amp \leq \left\Vert f- \sum_{k=1}^n a_k \chi_{A_k} \right\Vert_1 + \left\Vert \sum_{k=1}^n a_k \chi_{A_k}- \sum_{k=1}^n a_k \chi_{E_k} \right\Vert_1 \\ \amp \leq \left\Vert f- \sum_{k=1}^n a_k \chi_{A_k} \right\Vert_1 + \left\Vert \sum_{k=1}^n a_k \chi_{A_k}- \sum_{k=1}^n a_k \chi_{E_k} \right\Vert_1 \\ \amp < \epsilon + \epsilon \sum_{k=1}^n |a_k| \end{align*}
    🔗
    Since \(\epsilon > 0\) can be made arbitrarily small, the last line can be made as small as we desire. Thus we can approximate \(f\) by step functions.
    🔗
    🔗
    Finally we approximate \(\mathcal{L}^1\) functions by continuous functions.
    🔗

    Theorem 95. Approximation by Continuous Functions.

    Suppose \(f \in \mathcal{L}^1(\mathbf{R})\text{.}\) Then for every \(\epsilon > 0\) there exists a continuous function \(g: \mathbf{R} \to \mathbf{R}\) such that
    \begin{equation*} ||f-g||_1 < \epsilon \end{equation*}
    and \(\{x \in \mathbf{R}: g(x) \neq 0\}\) is a bounded set.
    🔗
    🔗

    Proof.

    The idea of the proof is that we can approximate step functions by continuous functions by connecting the pieces with lines.
    🔗
    For every \(a_1, \ldots a_n\text{,}\) \(b_1, \ldots b_n\text{,}\) \(c_1, \ldots c_n \in \mathbf{R}\) and \(g_1 \ldots g_n \in \mathcal{L}^1(f)\) it follows from the properties of the \(\mathcal{L}^1\) norm that
    \begin{align*} \left\Vert f- \sum_{k=1}^n a_k g_k \right\Vert_1 \amp \leq \left\Vert f- \sum_{k=1}^n a_k \chi_{[b_k,c_k]} \right\Vert_1 + \left\Vert \sum_{k=1}^n a_k(\chi_{[b_k, c_k]}-g_k) \right\Vert_1\\ \amp \leq \left\Vert f- \sum_{k=1}^n a_k \chi_{[b_k,c_k]} \right\Vert_1 + \sum_{k=1}^n |a_k| \cdot ||\chi_{[b_k, c_k]}-g_k||_1 \end{align*}
    🔗
    Since we can approximate \(\mathcal{L}^1\) functions by step functions, we can find numbers \(b_k\) and \(c_k\) to make \(\displaystyle \left\Vert f- \sum_{k=1}^n a_k \chi_{[b_k,c_k]} \right\Vert_1\) as small as we want.
    🔗
    As in the picture, we can construct continuous functions \(g_1, g_2, \ldots, g_n\) so that \(\displaystyle \sum_{k=1}^n |a_k| \cdot ||\chi_{[b_k, c_k]}-g_k||_1\) is as small as we want. Thus letting \(g = \displaystyle \sum_{k=1}^n a_k g_k\) gives us a continuous function that can be made arbitrarily close to \(f\) as desired.
