    Section Week 9: The Hardy-Littlewood Maximal Function (4A)

    Subsection Markov’s Inequality and the Vitali Covering Lemma

    In this chapter, we introduce the Hardy-Littlewood maximal function, which is of great importance in measure theory. We will use the Hardy-Littlewood maximal function to prove the fundamental theorem of calculus for Lebesgue integrable functions. Before we define the Hardy-Littlewood maximal function, we introduce a couple key theorems that we will need in the chapter.
    🔗

    Theorem 98. Markov’s Inequality.

    Suppose \((X,S,\mu)\) is a measure space and \(h \in \mathcal{L}^1(\mu)\text{.}\) Then for every \(c < 0\text{,}\)
    \begin{equation*} \mu(\{x\in X: |h(x)| \geq c\}) \leq \frac{1}{c} ||h||_1. \end{equation*}
    🔗
    🔗

    Theorem 99. Markov’s Inequality (Probability Version).

    If \(X\) is a non-negative random variable and \(c < 0\text{,}\) then the probability that \(X\) is at least \(c\) is at most the expected value of \(X\) divided by \(c\text{.}\)
    \begin{equation*} P(X \geq c) \leq \frac{E[X]}{c} \end{equation*}
    🔗
    🔗

    Proof.

    Suppose \(c < 0\text{.}\) Then
    \begin{align*} \mu(\{x\in X: |h(x)| \geq c\}) \amp = \frac{1}{c} \int_{\{x\in X: |h(x)| \geq c\}} c d\mu \\ \amp \leq \frac{1}{c} \int_{\{x\in X: |h(x)| \geq c\}} |h| d\mu\\ \amp = \frac{1}{c} ||h||_1 \end{align*}
    as desired.
    🔗
    🔗

    Definition 100.

    Suppose \(I\) is a bounded non-empty open interval of \(\mathbf{R}\text{.}\) Then \(3* I\) denotes the open interval with the same center as \(I\) and \(3\) times the length as \(I\text{.}\)
    🔗
    🔗
    Example: Suppose \(I = (-2,10)\text{.}\) Since the center of \(I\) is \(4\text{,}\) and the radius of \(I\) is \(6\text{,}\) \(3*I = (4-18,4+18) = (-14,22)\text{.}\)
    🔗

    Theorem 101. Vitali Covering Lemma.

    Suppose \(I_1, \ldots, I_n\) is a list of bounded non-empty open intervals of \(\mathbf{R}\text{.}\) Then there exists a disjoint sublist \(I_{k_1}, \ldots I_{k_m}\) such that
    \begin{equation*} I_1 \cup \ldots I_n \subset (3*I_{k_1}) \cup \ldots \cup (3*I_{k_m}). \end{equation*}
    🔗
    🔗
    The importance of the Vitali Covering Lemma is that it allows us to replace an arbitrary collection of intervals with a disjoint collection.
    🔗
    Example: Let \(I_1 = (0,4)\text{,}\) \(I_2 = (-3,3)\text{,}\) \(I_3 = (2,10)\) and \(I_4 = (-7,1)\text{.}\) Then \(3*I_1 = (-4,8)\text{,}\) \(3*I_2 = (-9,9)\text{,}\) \(3*I_3 = (-6,18)\text{,}\) and \(3*I_4 = (-15,9)\text{.}\) \(I_1 \cup I_2 \cup I_3 \cup I_4 = (-7,10) \subset 3*I_3 \cup 3*I_4\) which satisfies the conclusion of the Vitali covering Lemma.
    🔗

    Proof.

    We choose our disjoint sublist in the following way. Let \(I_{k_1}\) be the longest interval on the list. (If multiple intervals are tied for longest, choose one of them arbitrarily.) Now choose \(I_{k_2}\) to be the longest remaining interval on the list that is disjoint from \(I_{k_1}\text{.}\)
    🔗
    We inductively repeat this process. If \(I_{k_1}, \ldots, I_{k_j}\) have already been chosen, then choose \(I_{k_{j+1}}\) to be the longest remaining interval that is disjoint from the ones already chosen. When there are no more intervals left that are disjoint from the ones previously chosen, the process terminates and the intervals already chosen form our sublist.
    🔗
    Example: If we apply this procedure to the previous example, both \(I_3 = (2,10)\) and \(I_4 = (-7,1)\) have length \(8\text{,}\) so we arbitrarily choose one to be the first interval in the sublist. Since \(I_3\) and \(I_4\) are disjoint, we choose the other one to be the second interval in the sublist. None of the other intervals are disjoint, so our sublist only consists of \(I_3\) and \(I_4\text{.}\)
    🔗
    Suppose \(j \in \{1, \ldots, n\}\text{.}\) To complete the proof we must show that \(I_j \subseteq 3*I_{k_1} \cup 3*I_{k_m}\text{.}\) If \(j \in \{k_1, \ldots, k_m\}\) then this is true, so we can suppose that \(j \notin \{k_1, \ldots, k_m\}\text{.}\) This means that \(I_j\) is an interval that was not chosen on our sublist, so it is not disjoint from all of \(I_{k_1}, \ldots I_{k_m}\text{.}\)
    🔗
    Let \(I_{k_L}\) be the first interval on the sublist that is not disjoint from \(I_j\text{.}\) This means that \(I_j\) is disjoint from all of \(I_{k_1} \ldots I_{k_{L-1}}\text{.}\) Because \(I_{k_L}\) was chosen instead of \(I_j\) to be on the sublist, this means that \(|I_{k_L}| \geq |I_j|\text{.}\) This implies that \(I_j \subseteq 3*I_{k_L}\) and the lemma is proved.
    🔗
    To see this, shift the intervals so that \(I_{k_L}\) is centered at \(0\text{.}\) Then \(I_{k_L} = (-a,a)\text{.}\) Since \(I_j\) is not disjoint, it has the form \((b,c)\) where \(b < a\) and \(c-b \leq 2a\text{.}\) Hence \(c < 3a\) and \(I_j \subseteq 3*I_{k_L}\text{.}\)
    🔗
    🔗
    🔗

    Subsection Hardy Littlewood Maximal Inequality

    Definition 102. Hardy-Littlewood Maximal Function, \(h^*\).

    Suppose \(h: \mathbf{R} \to \mathbf{R}\) is a Lebesgue measurable function. Then the Hardy-Littlewood maximal function of \(h\) is the function \(h^*: \mathbf{R} \to [0,\infty]\) defined by
    🔗
    \begin{equation*} h^*(b) = \sup_{t>0} \frac{1}{2t} \int_{b-t}^{b+t} |h|. \end{equation*}
    🔗
    In other words \(h^*(b)\) is the supremum of the average of \(h\text{,}\) where the supremum is taken over all bounded intervals centered at \(b\text{.}\)
    🔗
    Example: Let \(h = \chi_{[0,1]}\) denote the characteristic function on \([0,1]\text{.}\) Find \(h^*(b)\text{.}\)
    🔗
    Markov’s inequality gives an estimate for the size of the set on which \(h < c\text{.}\) The next result gives an estimate for the size of the set on which \(h^*(b) < c\)
    🔗

    Theorem 103. Hardy-Littlewood Maximal Inequality.

    Suppose \(h \in \mathcal{L}^1(\mathbf{R})\text{.}\) Then
    \begin{equation*} |\{b\in \mathbf{R}: h^*(b) > c\}| \leq \frac{3}{c} ||h||_1 \end{equation*}
    for every \(c < 0\text{.}\)
    🔗
    🔗

    Proof.

    Suppose that \(F\) is a closed bounded subset of \(\{b\in \mathbf{R}: h^*(b) < c\}\text{.}\) We will show that
    \begin{equation*} |F| \leq \frac{3}{c} \int_{-\infty}^{\infty} |h|. \end{equation*}
    🔗
    Assuming that we have shown this, then by taking the supremum over all closed bounded subsets of \(\{b\in \mathbf{R}: h^*(b) < c\}\) gives the desired result.
    🔗
    It follows from how the Hardy-Littlewood maximal function is defined that for each \(b \in F\text{,}\) there exists \(t_b> 0\) such that
    \begin{equation*} \frac{1}{2t_b} \int_{b-t_b}^{b+t_b} |h| > c. \end{equation*}
    🔗
    Since
    \begin{equation*} F \subseteq \bigcup_{b \in F} (b-t_b, b+t_b), \end{equation*}
    it follows from the Heine-Borel Theorem that this open cover has a finite subcover.
    🔗
    This means that there exists \(b_1, \ldots b_n \in F\) such that
    \begin{equation*} F \subseteq (b_1 -t_{b_1}, b_1 + t_{b_1}) \cup \ldots \cup (b_n - t_{b_n}, b_n + t_{b_n}) \end{equation*}
    🔗
    For clarity, let’s relabel the above open intervals as \(I_1, \ldots, I_n\text{.}\) By the Vitali Covering Lemma, there exits disjoint subsets \(I_{k_1}, \ldots I_{k_m}\) of the open intervals such that
    \begin{equation*} I_1, \ldots, I_n \subseteq (3*I_{k_1} \cup \ldots \cup (3*I_{k_m}) \end{equation*}
    🔗
    Hence,
    \begin{align*} |F| \amp \leq |I_1 \cup \ldots \cup I_n| \\ \amp \leq |(3*I_{k_1}) \ldots (3*I_{k_m})|\\ \amp \leq |3*I_{k_1}| + \ldots + |3*I_{k_m}|\\ \amp = 3(|I_{k_1}| + \ldots + |I_{k_m}|). \end{align*}
    🔗
    Now \(|I_{k_j}| = 2t_b\) for the choice of \(t_b\) that corresponds to \(I_{k_j}\text{.}\) Hence it follows from the definition of the Hardy-Littlewood maximal function that
    \begin{equation*} \frac{1}{|I_{k_j}|} \int_{b-t_b}^{b+t_b} |h| > c. \end{equation*}
    🔗
    Rearranging this inequality gives that
    \begin{equation*} |I_{k_j}| < \frac{1}{c} \int_{b-t_b}^{b+t_b} |h|. \end{equation*}
    Hence it follows that
    \begin{equation*} |F| \leq \frac{3}{c} \left(\int_{I_{k_1}} |h| + \ldots + \int_{I_{k_m}} |h| \right). \end{equation*}
    🔗
    Since \(I_{k_1}, \ldots, I_{k_m}\) are disjoint, we conclude that
    \begin{equation*} |F| \leq \frac{3}{c} \int_{-\infty}^{\infty} |h|, \end{equation*}
    which is what we want to prove.
