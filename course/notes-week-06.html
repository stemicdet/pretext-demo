    Section Week 6: Convergence of Measurable Functions (2E)

    Subsection Littlewood’s Three Principles

    Recall the definitions of pointwise and uniform convergence.
    🔗

    Definition 60. Pointwise and Uniform Convergence.

    Suppose \(X\) is a set, \(f_1, f_2, \ldots\) are functions from \(X\) to \(\mathbf{R}\) and \(f\) is a function from \(X\) to \(\mathbf{R}\text{.}\)
    🔗
    • The sequence \(f_1, f_2, \ldots \) converges pointwise on \(X\) to \(f\) if
      \begin{equation*} \lim_{k\to \infty} f_k(x) = f(x) \end{equation*}
      for each \(x \in X\text{.}\) In other words, \(f_1, f_2, \ldots\) converges pointwise on \(X\) to \(f\) if for each \(x \in X\) and every \(\epsilon > 0\) there exists \(n \in \mathbf{N}\) such that \(|f_k(x)-f(x)| < \epsilon\) for all integers \(k \geq n\text{.}\)
      🔗
      🔗
    • The sequence \(f_1, f_2, \ldots\) converges uniformly on \(X\) to \(f\) if for every \(\epsilon > 0\) there exists \(n \in \mathbf{N}\) such that \(|f_k(x)-f(x)| < \epsilon\) for all integers \(k \geq n\) and all \(x \in X\text{.}\)
      🔗
      🔗
    🔗
    Example: Let \(g_n(x) = x^n\) on \([0,1]\text{.}\) Then \(g(x)\) converges pointwise to
    \begin{equation*} g(x) = \begin{cases} \hfill 0 \amp \text{ if $ 0 \leq x < 1$} \\ \hfill 1 \hfill \amp \text{ if $x = 1$} \end{cases} \end{equation*}
    However, \(g_n(x)\) does not converge uniformly on \([0,1]\text{.}\)
    🔗
    The previous example shows that the pointwise limit of a sequence of continuous functions need not be continuous; however, the uniform limit of a sequence of continuous functions will always be continuous.
    🔗

    Theorem 61. Uniform Limit of a Sequence of Continuous Function is Continuous.

    Suppose \(B \subseteq \mathbf{R}\) and \(f_1, f_2, \ldots\) is a sequence of functions from \(B\) to \(\mathbf{R}\text{.}\) Suppose \(b \in B\) and \(f_k\) is continuous at \(b\) for each \(k \in \mathbf{R}\text{.}\) Then \(f\) is continuous at \(B\text{.}\)
    🔗
    🔗
    The following propositions are clearly false.
    🔗
    1. Every measurable set is a finite union of intervals.
      🔗
      🔗
    2. Every measurable function is continuous.
      🔗
      🔗
    3. Every pointwise convergent sequence is uniformly convergent.
      🔗
      🔗
    However, it only takes a slight modification to change them into true statements. These are called Littlewood’s Three Principles. The following are true statements.
    🔗
    1. Every measureable set is nearly a finite union of intervals.
      🔗
      🔗
    2. Every measurable function is nearly continuous.
      🔗
      🔗
    3. Every pointwise convergent sequence is nearly uniformly convergent.
      🔗
      🔗
    Here nearly means that the statement holds outside a set with arbitrarily small measure.
    🔗
    🔗

    Subsection Egorov’s Theorem

    We essentially proved (a) in our theorem of equivalences of being a Lebesgue measurable set. Next we will prove (c).
    🔗

    Theorem 62. Egorov’s Theorem.

    Suppose \((X,S,\mu)\) is a measure space with \(\mu(X) < \infty\text{.}\) Suppose \(f_1,f_2, \ldots\) is a sequence of \(S\)-measurable functions from \(X\) to \(\mathbf{R}\) that converges pointwise on \(X\) to a function \(f:X \to \mathbf{R}\text{.}\) Then for every \(\epsilon > 0\) there exists a set \(E \in S\) such that \(\mu(X \setminus E) < \epsilon\) and \(f_1,f_2,\ldots\) converges uniformly to \(f\) on \(X\text{.}\)
    🔗
    🔗
    Example: Consider the sequence \(g_n(x) = x^n\text{,}\) which is a sequence of Lebesgue measurable functions from \(X = [0,1]\) to \(\mathbf{R}\) which converges pointwise to
    \begin{equation*} g(x) = \begin{cases} \hfill 0 \amp \text{ if $ 0 \leq x < 1$} \\ \hfill 1 \hfill \amp \text{ if $x = 1$} \end{cases} \end{equation*}
    🔗
    Given \(\epsilon > 0\text{,}\) let \(E = [0, 1-\frac{\epsilon}{2}]\text{.}\) Then \(\mu(X \setminus E) = \frac{\epsilon}{2} < \epsilon\) and \(g_n(x)\) converges uniformly to \(g(x)\) on \(E\text{.}\)
    🔗

    Proof.

    Suppose \(\epsilon > 0\) and temporarily fix \(n \in \mathbf{N}\text{.}\) Because \(\{f_n\}\) converges pointwise to \(f\text{,}\) we have that
    \begin{equation*} \bigcup_{m=1}^{\infty} \bigcap_{k=m}^{\infty} \left\{x\in X: |f_k(x)-f(x)| < \frac{1}{n}\right\} = X \end{equation*}
    🔗
    For \(m \in \mathbf{N}\) let
    \begin{equation*} A_{m,n} = \bigcap_{k=m}^{\infty} \left\{x\in X: |f_k(x)-f(x)| < \frac{1}{n}\right\}. \end{equation*}
    🔗
    Because each \(f_k\) is an \(S\)-measurable function \(f\) is an \(S\)-measurable function. Hence each \(f_k-f\) is an \(S\)-measurable function and \(A_{m,n} \in S\text{.}\)
    🔗
    Since \(A_{1,n} \subseteq A_{2,n} \subseteq \ldots\) is an increasing sequence of sets and
    \begin{equation*} \bigcup_{m=1}^{\infty} A_{m,n} = X \end{equation*}
    it follows that \(\displaystyle \lim_{m\to \infty} \mu(A_{m,n}) = \mu(X)\text{.}\)
    🔗
    Thus there exists \(m_n \in \mathbf{N}\) such that \(\mu(X) - \mu(A_{m_n,n}) < \frac{\epsilon}{2^n}\text{.}\)
    🔗
    Now let \(E = \displaystyle \bigcap_{n=1}^{\infty} A_{m_n,n}\text{.}\) Then
    \begin{align*} \mu(X \setminus E) \amp \left( X \setminus \bigcap_{n=1}^{\infty} A_{m_n,n} \right) \\ \amp = \mu \left( \bigcup_{n=1}^{\infty} X \setminus A_{m_n,n} \right)\\ \amp \leq \sum_{n=1}^{\infty} \mu(X \setminus A_{m_n,n})\\ \amp \leq \sum_{n=1}^{\infty} \mu(X) - \mu(A_{m_n,n}) = \epsilon. \end{align*}
    🔗
    To complete the proof, we need to show that the sequence \(f_1, f_2, \ldots\) converges to \(f\) uniformly on \(E\text{.}\) Suppose \(\epsilon' > 0\) and let \(n \in \mathbf{N}\) be such that \(\frac{1}{n} < \epsilon'\text{.}\) Then because \(E \subseteq A_{m_n,n}\) we have that
    \begin{equation*} |f_k(x)-f(x)| < \frac{1}{n} < \epsilon' \end{equation*}
    for all \(k \geq m_n\) and \(x \in E\text{.}\) Hence \(f_1, f_2, \ldots\) converges uniformly to \(f\) on \(E\text{.}\)
    🔗
    🔗
    🔗

    Subsection Approximation by Simple Functions

    The simplest function is a constant function, since it only attains a single value. The next simplest are functions that only attain a finite number of values.
    🔗

    Definition 63. Simple Function.

    A function is called simple if it takes on only a finite number of values.
    🔗
    🔗
    Example: Dirichlet’s function
    \begin{equation*} f(x) = \begin{cases} \hfill 1 \amp \text{ if $x \in \mathbf{Q}$} \\ \hfill 0 \hfill \amp \text{ if $x \notin \mathbf{Q}$} \end{cases} \end{equation*}
    is a simple function since it only takes on 2 values.
    🔗
    Suppose \((X,S)\) is a measurable space, \(f: X \to \mathbf{R}\) is a simple function and \(c_1, c_2, \ldots c_n\) are the distinct nonzero values of \(f\text{.}\) Then \(f = c_1 \chi_{E_1} + c_2 \chi_{E_2} + \ldots + c_n \chi_{E_n}\) where \(E_k = f^{-1}(c_k)\text{.}\) This function is an \(S\)-measurable function if and only if all \(E_k \in S\text{.}\)
    🔗

    Theorem 64. Approximation by Simple Functions.

    Suppose \((X,S)\) is a measurable space and \(f:X \to [-\infty, \infty]\) is \(S\)-measurable. Then there exists a sequence \(f_1, f_2, \ldots,\) of functions from \(X\) to \(\mathbf{R}\) such that
    1. Each \(f_k\) is a simple \(S\)-measurable function.
      🔗
      🔗
    2. \(|f_k(x)| \leq |f_{k+1}(x)| \leq |f(x)|\) for all \(k \in \mathbf{N}\) and \(x \in X\text{.}\)
      🔗
      🔗
    3. \(\displaystyle \lim_{k\to \infty} f_k(x) = f(x)\) for every \(x \in X\text{.}\)
      🔗
      🔗
    4. \(f_1, f_2, \ldots\) converges uniformly to \(f\) if \(f\) is bounded.
      🔗
      🔗
    🔗
    🔗

    Proof.

    Define \(f_k(x)\) by
    \begin{equation*} f_k(x) = \begin{cases} \hfill \frac{m}{2^k} \amp \text{ if $0 \leq f(x) \leq k$ and $m \in \mathbf{Z}$ is such that $f(x) \in [\frac{m}{2^k}, \frac{m+1}{2^k})$} \\ \hfill \frac{m+1}{2^k} \amp \text{ if $-k \leq f(x) < 0$ and $m \in \mathbf{Z}$ is such that $f(x) \in [\frac{m}{2^k}, \frac{m+1}{2^k})$} \\ \hfill k \amp \text{ if $f(x) > k$} \\ \hfill -k \amp \text{ if $f(x) < -k$} \\ \end{cases} \end{equation*}
    🔗
    In other words, we divide \([-k,k]\) into equally spaced subintervals. If \(f(x) \in [0,k]\) we define \(f_k(x)\) to be the left endpoint of the subinterval it’s in and if \(f(x) \in [-k,0)\) we define \(f_k(x)\) to be the right endpoint of the subintervals it’s in. If \(|f(x)| > k\) then we define \(f_k(x) = \pm k\text{.}\)
    🔗
    For each \(k\text{,}\) \(f_k(x)\) only attains a finite number of values, so it is a simple function. Moreover, because \(f\) is an \(S\)-measurable function \(f^{-1}\left([\frac{m}{2^k}, \frac{m+1}{2^k})\right) \in S\text{.}\)
    🔗
    Thus for each \(y \in \mathbf{R}\) \(f_k^{-1}(y)\) is a Borel set and thus \(f_k\) is also an \(S\)-measurable function, proving (a). Also (b) holds because of how we define \(f_k(x)\text{.}\) For example if \(k < j\) and \(f(x)\) is in \([\frac{m}{2^k}, \frac{m+1}{2^k})\) and also in \([\frac{p}{2^j}, \frac{p+1}{2^j})\text{,}\) then \(\frac{m}{2^k} < \frac{p}{2^j}\text{.}\)
    🔗
    It follows from how we defined \(f_k\) that
    \begin{equation*} |f_k(x)-f(x)| \leq \frac{1}{2^k} \end{equation*}
    for all \(x\) such that \(f(x) \in [-k,k]\text{.}\) Hence for each \(x \in X\text{,}\) \(\displaystyle \lim_{k\to \infty} f_k(x) = f(x)\text{.}\) Thus (c) is proved.
    🔗
    Finally if \(f\) is bounded then there exists some \(K\) such that for all \(x\) \(f(x) \in [-K,K]\) and thus the previous limit gives that \(\{f_k\}\) converges uniformly to \(f\text{,}\) proving (d).
    🔗
    🔗
    🔗

    Subsection Luzin’s Theorem

    Now we will prove the second of Littlewood’s Three Principles.
    🔗

    Theorem 65. Luzin’s Theorem.

    Suppose \(g: \mathbf{R} \to \mathbf{R}\) is a Borel Measurable function. Then for every \(\epsilon>0\) there exists a closed set \(F \subseteq \mathbf{R}\) such that \(|\mathbf{R} \setminus F| < \epsilon\) and \(g|_F\) is a continuous function on \(F\text{.}\)
    🔗
    🔗
    Note that Luzin’s Theorem does not say that \(g\) is continuous on \(F\text{,}\) only that \(g|_F\) is continuous on \(F\text{.}\) For example, Dirichlet’s function
    \begin{equation*} g(x) = \begin{cases} \hfill 1 \amp \text{ if $x \in \mathbf{Q}$} \\ \hfill 0 \hfill \amp \text{ if $x \notin \mathbf{Q}$} \end{cases} \end{equation*}
    is nowhere continuous on \(\mathbf{R}\text{.}\) Let \(\epsilon > 0\) and let \(G\) be an open cover of \(\mathbf{Q}\) with \(|G| < \epsilon\text{.}\) Let \(F = \mathbf{R} \setminus G\text{.}\) Then \(F\) is a closed set and \(|\mathbf{R} \setminus F| < \epsilon\text{.}\) Since \(g(x) = 0\) on \(F\text{,}\) \(g|_F\) is a continuous function on \(F\text{.}\)
    🔗

    Proof.

    We will build up the proof through a series of special cases. First consider the case that \(g\) is a simple function. Recall that this means that \(g\) can be written as
    \begin{equation*} g = d_1 \chi_{D_1} + d_2 \chi_{D_2} + \ldots + d_n \chi_{D_n} \end{equation*}
    where \(d_1, \ldots d_n\) are distinct nonzero real numbers and \(D_1, \ldots D_n\) are disjoint Borel sets.
    🔗
    Suppose \(\epsilon>0\text{.}\) Then for each \(k \in \{1,2, \ldots n\}\) there exists a closed set \(F_k \subseteq D_k\) and an open set \(G_k \supseteq D_k\) such that
    \begin{equation*} |G_k \setminus D_k| < \frac{\epsilon}{2n} \text{ and } |D_k \setminus F_k| < \frac{\epsilon}{2n}. \end{equation*}
    🔗
    Because \(G_k \setminus F_k = (G_k \setminus D_k) \cup (D_k \setminus F_k)\text{,}\) we have that \(|G_k \setminus F_k| < \frac{\epsilon}{2n} + \frac{\epsilon}{2n} = \frac{\epsilon}{n}\) for each \(k \in \mathbf{N}\text{.}\) Now let
    \begin{equation*} F = \left( \bigcup_{k=1}^n F_k \right) \cup \bigcap_{k=1}^n \left( \mathbf{R} \setminus G_k \right). \end{equation*}
    🔗
    Since \(F\) is a finite union of closed sets, \(F\) is closed. Moverover,
    \begin{equation*} \mathbf{R} \setminus F \subseteq \bigcup_{k=1}^n G_k \setminus F_k \end{equation*}
    and hence \(\displaystyle |\mathbf{R}\setminus F| \leq \sum_{k=1}^n \frac{\epsilon}{n} = \epsilon\text{.}\) Thus it remains to show that \(g|_F\) is a continuous function on \(F\text{.}\)
    🔗
    Because \(F_k \subseteq D_k\) it follows that \(g(x) = d_k\) on \(F_k\text{.}\) Thus \(g\) is continuous on \(F_k\) for all \(k \in \{1, \ldots, n\}\text{.}\) In addition, since
    \begin{equation*} \bigcap_{k=1}^n \mathbf{R} \setminus G_k \subseteq \bigcap_{k=1}^n \mathbf{R} \setminus D_k \end{equation*}
    it follows that \(g(x) = 0\) on this set, and hence \(g\) is continuous here as well. Thus \(g\) is continuous on \(F\) and the theorem is proven for simple functions.
    🔗
    Now suppose that \(g\) is an arbitrary Borel function. Then there is a sequence of simple Borel measurable functions \(g_1, g_2, \ldots\) that converges to \(g\text{.}\) Suppose \(\epsilon > 0\text{.}\) Then by the special case we just proved, for each \(k\) there exists a closed set \(C_k\) such that \(|\mathbf{R} \setminus C_k| < \frac{\epsilon}{2^{k+1}}\) and \(g_k|_{C_k}\) is continuous on \(C_k\text{.}\)
    🔗
    Let
    \begin{equation*} C = \bigcap_{k=1}^{\infty} C_k. \end{equation*}
    Then \(C\) is a closed set and \(g_k|_C\) is continuous on \(C\) for all \(k\text{.}\) Note that
    \begin{equation*} \mathbf{R} \setminus C = \bigcup_{k=1}^{\infty} \mathbf{R} \setminus C_k. \end{equation*}
    Hence
    \begin{equation*} |\mathbf{R}\setminus C| \leq \sum_{k=1}^{\infty} |\mathbf{R}\setminus C_k| < \sum_{k=1}^{\infty} \frac{\epsilon}{2^{k+1}} = \frac{\epsilon}{2}. \end{equation*}
    🔗
    For each \(m \in \mathbf{Z}\) the sequence \(g_1|_{(m,m+1)}, g_2|_{(m,m+1)}, \ldots\) converges pointwise on \((m,m+1)\) to \(g|_{(m,m+1)}\text{.}\) Thus by Egorov’s Theorem for each \(m \in \mathbf{Z}\) there is a Borel set \(E_m \subseteq (m,m+1)\) such that \(g_1, g_2, \ldots\) converges uniformly to \(g\) and
    \begin{equation*} |(m, m+1) \setminus E_m| \leq \frac{\epsilon}{2^{|m|+3}}. \end{equation*}
    🔗
    Hence \(g_1, g_2, \ldots\) converges uniformly to \(g\) on \(C \cap E_m\) for each \(m \in \mathbf{Z}\text{.}\) Since each \(g_k|_C\) is continuous it follows that \(g\) is continuous on \(C \cap E_m\) for each \(m \in \mathbf{Z}\text{.}\) Thus \(g|_D\) is continuous, where
    \begin{equation*} D = \bigcup_{m \in \mathbf{Z}} C \cap E_m. \end{equation*}
    🔗
    Now
    \begin{equation*} \mathbf{R} \setminus D \subseteq \left(\mathbf{R}\setminus C\right) \cup \bigcup_{m \in \mathbf{Z}} \left((m,m+1) \setminus E_m) \right) \cup \mathbf{Z}. \end{equation*}
    Hence
    \begin{align*} |\mathbf{R}\setminus D| \amp \leq |\mathbf{R}\setminus C| + \sum_{m\in \mathbf{Z}} |(m, m+1) \setminus E_m| + |\mathbf{Z}| \\ \amp < \frac{\epsilon}{2} + \sum_{m\in \mathbf{Z}}\frac{\epsilon}{2^{|m|+3}} + 0 \\ \amp = \frac{\epsilon}{2} + \frac{\epsilon}{8} + 2\sum_{m=1}^{\infty}\frac{\epsilon}{2^{m+3}} \\ \amp =\frac{\epsilon}{2} + \frac{\epsilon}{8} + \frac{\epsilon}{4} < \epsilon. \end{align*}
    Hence \(|\mathbf{R}\setminus D| < \epsilon\text{.}\)
    🔗
    Since \(D\) is a Borel set, we can approximate it from below by closed sets. This means there exists a closed set \(F\) such that \(F \subseteq D\) and \(|D \setminus F| < \epsilon - |\mathbf{R} \setminus D|\text{.}\)
    🔗
    Hence
    \begin{equation*} |\mathbf{R} \setminus F| = |(\mathbf{R} \setminus D) \cup (D \setminus F)| \leq |\mathbf{R}\setminus D| + |D \setminus F| = \epsilon. \end{equation*}
    🔗
    Thus \(F\) is a closed set with \(|\mathbf{R} \setminus F| < \epsilon\text{.}\) Moreover, since a continuous function is still continuous when restricted to a smaller set, \(g|_F\) is continuous on \(F\text{,}\) which completes the proof.
    🔗
    🔗
    There is another version of Luzin’s Theorem which is sometimes more useful.
    🔗

    Theorem 66. Luzin’s Theorem, Second Version.

    Suppose \(E \subseteq \mathbf{R}\) and \(g: E \to \mathbf{R}\) is a Borel measurable function. Then for every \(\epsilon > 0\) there exists a closed set \(F \subseteq E\) and a continuous function \(h: \mathbf{R} \to \mathbf{R}\) such that \(|E \setminus F| < \epsilon\) and \(h|_F = g|_F\text{.}\)
    🔗
    🔗
    See the textbook for the proof

    Subsection Lebesgue Measurable Functions

    Definition 67. Lebesgue Measurable Function.

    A function \(f: A \to \mathbf{R}\) is called Lebesgue measurable if \(f^{-1}(B)\) is a Lebesgue measurable set for every Borel set \(B\) in \(\mathbf{R}\text{.}\)
    🔗
    🔗
    Recall that a Lebesgue measurable set differs from a Borel set by a set with outer measure \(0\text{.}\) Likewise we expect that every Lebesgue measurable function is nearly a Borel measurable function.
    🔗

    Theorem 68. Every Lebesgue Measurable Function is Almost Borel Measurable.

    Suppose \(f: \mathbf{R} \to \mathbf{R}\) is a Lebesgue measurable function. Then there exists a Borel measurable function \(g: \mathbf{R} \to \mathbf{R}\) such that
    \begin{equation*} |\{x \in \mathbf{R}: g(x) \neq f(x)\}| = 0. \end{equation*}
    🔗
    🔗

    Proof.

    There exists a sequence \(f_1, f_2, \ldots\) of Lebesgue measurable simple functions that converges pointwise to \(f\text{.}\) This means that for each \(k \in \mathbf{N}\text{,}\) there exists \(c_1, \ldots, c_n \in \mathbf{R}\) and disjoint Lebesgue measurable sets \(A_1, \ldots A_n\) such that
    \begin{equation*} f_k = c_1 \chi_{A_1} + c_2 \chi_{A_2} + \ldots c_n \chi_{A_n}. \end{equation*}
    🔗
    We now approximate these Lebesgue measurable sets by Borel sets. For each \(j \in \{1, \ldots, n\}\) there exists a Borel set \(B_j\) such that \(|A_j \setminus B_j| = 0\text{.}\) Let
    \begin{equation*} g_k = c_1 \chi_{B_1} + c_2 \chi_{B_2} + \ldots c_n \chi_{B_n}. \end{equation*}
    Then \(g_k\) is a Borel measurable function and \(|\{x \in \mathbf{R}: g_k(x) \neq f_k(x)\}| = 0\text{.}\)
    🔗
    We will show that the sequence \(\{g_k\}\) converges to the Borel measurable function that we want. If \(x \notin \displaystyle \bigcup_{k=1}^{\infty} \{x \in \mathbf{R}: g_k(x) \neq f_k(x)\}\text{,}\) then \(g_k(x) = f_k(x)\) for all \(k \in \mathbf{N}\) and hence \(\lim_{k \to \infty} g_k(x) = f(x)\text{.}\)
    🔗
    Let \(\displaystyle E = \{x \in \mathbf{R}: \lim_{k\to \infty} g_k(x) \text{ exists in } \mathbf{R}\}\text{.}\) It follows from an exercise in the book (#14 b in Section 2B) that \(E\) is a Borel subset of \(\mathbf{R}\text{.}\) Also,
    \begin{equation*} \mathbf{R} \setminus E \subseteq \bigcup_{k=1}^{\infty} \{x\in \mathbf{R}: g_k(x) \neq f_k(x)\}. \end{equation*}
    🔗
    Since \(\mathbf{R} \setminus E\) is contained in a countable union of sets with measure \(0\text{,}\) it follows that \(|\mathbf{R} \setminus E| = 0\text{.}\)
    🔗
    Let \(g(x) = \lim_{k\to \infty} (\chi_E g_k)(x)\text{.}\) If \(x \in E\text{,}\) then the limit exists because of how we defined \(E\text{,}\) and if \(x\notin E\text{,}\) then \(\chi_E = 0\) and the limit is \(0\) and hence exists. So \(g(x)\) is well defined. Since the product of Borel measurable functions is a Borel measurable function it follows that for each \(k \in \mathbf{N}\text{,}\) \(\chi_E g_k\) is a Borel measurable function. Since the pointwise limit of a sequence of Borel measurable functions is Borel measurable, it follows that \(g\) is a Borel measurable function.
    🔗
    Finally,
    \begin{equation*} \{x\in \mathbf{R}: g(x) \neq f(x) \} \subseteq \bigcup_{k=1}^{\infty} \{x\in \mathbf{R}: g_k(x) \neq f_k(x) \}. \end{equation*}
    Thus \(\{x\in \mathbf{R}: g(x) \neq f(x) \}\) is contained in a countable union of sets with measure \(0\) and thus \(|\{x\in \mathbf{R}: g(x) \neq f(x) \}| = 0\text{.}\) Thus \(g\) is a Borel measurable function with \(|\{x\in \mathbf{R}: g(x) \neq f(x) \}| = 0\text{,}\) which completes the proof.
