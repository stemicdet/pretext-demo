    Section Week 4: Measures and Their Properties (2C)

    Subsection Definition and Examples of Measures

    The motivation for defining outer measure was to extend the concept of the length of an interval to all subsets of \(\mathbf{R}\text{.}\) However we will define a more general definition of measure which will also extend areas of squares and volumes of cubes to subsets of \(\mathbf{R^2}\) and \(\mathbf{R^3}\text{.}\)
    🔗

    Definition 35. Measure.

    Suppose \(X\) is a set and \(S\) is a \(\sigma\)-algebra on \(X\text{.}\) A \(measure\) on \((X,S)\) is a function \(\mu: S \to [0,\infty]\) such that \(\mu(\emptyset) = 0\) and
    \begin{equation*} \mu \left( \bigcup_{k=1}^{\infty} E_k \right) = \sum_{k=1}^{\infty} \mu(E_k) \end{equation*}
    for every sequence of disjoint subsets \(E_1, E_2, \ldots\) of sets in \(S\text{.}\)
    🔗
    🔗
    Example: Let \(X\) be a set and let \(S\) be the \(\sigma\)-algebra of all subsets of \(X\text{.}\) Define a measure on \(X\) by \(\mu(E) = n\) if \(E\) contains \(n\) elements and \(\mu(E) = \infty\) if \(E\) contains infinitely many elements. This \(\mu\) is called the counting measure.
    🔗
    Example: Let \(S\) be the \(\sigma\)-algebra of all subsets of \(\mathbf{R}\text{.}\) Then the outer measure on \(\mathbf{R}\) is not a measure on \((\mathbf{R},S)\) because it is not countably additive.
    🔗
    Example: Let \(S\) be the \(\sigma\)-algebra of all Borel subsets of \(\mathbf{R}\text{.}\) We will prove in the next section that the outer measure on \(\mathbf{R}\) is a measure on \((\mathbf{R},S)\text{.}\)
    🔗
    Example: Suppose \(S\) is a \(\sigma\)-algebra on a set \(X\text{.}\) A probability measure is a measure \(\mu\) on \((X,S)\) such that \(\mu(X) = 1\text{.}\)
    🔗
    \(X\) is called the sample space and a subset in \(S\) is called an event.
    🔗
    If \(A\) is an event then \(\mu(A)\) is called the probability of \(A\text{.}\)
    🔗
    Consider an experiment in which a 6 sided die is rolled. The sample space is the set \(X = \{1,2,3,4,5,6\}\text{.}\)
    🔗
    Let \(S\) be the \(\sigma\)-algebra of all subsets of \(X\) and let \(\mu\) be the measure on \((X,S)\) defined by \(\mu(E) = \frac{n}{6}\) where \(n\) is the number of elements of \(E\text{.}\) Then \(\mu\) is a probability measure on \((X,S)\text{.}\)
    🔗
    Let \(A\) be the event that the die lands on an even number. Then \(A = \{2,4,6\}\text{.}\) Hence \(\mu(A) = \frac{1}{2}\text{.}\)
    🔗
    Recall that a measurable space is a set \(X\) along with a \(\sigma\)-algebra \(S\text{.}\) If we include a measure \(\mu\) then we have a measure space.
    🔗

    Definition 36. Measure Space.

    A measure space is an ordered triple \((X,S,\mu)\) where \(X\) is a set, \(S\) is a \(\sigma\)-algebra on \(X\) and \(\mu\) is a measure on \((X,S)\text{.}\)
    🔗
    If \(\mu\) is a probability measure on \((X,S)\) then the triple \((X,S,\mu)\) is called a probability space.
    🔗
    🔗
    🔗

    Subsection Properties of Measures

    Theorem 37. Measures Preserve Order; Measure of Set Difference.

    Suppose \((X,S,\mu)\) is a measure space and \(D,E \in S\) such that \(D \subseteq E\text{.}\) Then
    1. \(\mu(D) \leq \mu(E)\text{.}\) (Measures are monotone.)
      🔗
      🔗
    2. \(\mu(E \setminus D) = \mu(E) - \mu(D)\) provided that \(\mu(D) < \infty\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Note that we need the condition that \(\mu(D) < \infty\) to avoid getting an indeterminate form of \(\infty - \infty\text{.}\)
    🔗

    Proof.

    We can rewrite \(E\) as \(E = D \bigcup E\setminus D\text{.}\) Because this is a disjoint union it follows from the countable additivity of measures that \(\mu(E) = \mu(D) + \mu(E\setminus D)\text{.}\)
    🔗
    Since \(\mu(E \setminus D) \geq 0\text{,}\) it follows that \(\mu(D) \leq \mu(E)\text{.}\)
    🔗
    Also if \(\mu(D) < \infty\) then subtracting \(\mu(D)\) on both sides of the equation gives that \(\mu(E \setminus D) = \mu(E) - \mu(D)\text{.}\)
    🔗
    🔗
    The countable additivity property of measures only applies to disjoint unions; however, measures satisfy the countable subadditivity property on arbitrary countable unions.
    🔗

    Theorem 38. Countable Subadditivity of Measures.

    Suppose \((X,S,\mu)\) is a measure space and \(E_1, E_2, \ldots\) are subsets in \(S\text{.}\) Then
    \begin{equation*} \mu \left(\bigcup_{k=1}^{\infty} E_k \right) \leq \sum_{k=1}^{\infty} \mu(E_k). \end{equation*}
    🔗
    🔗

    Proof.

    Let \(D_1 = \emptyset\) and \(D_k = E_1 \cup \ldots \cup E_{k-1}\) for \(k \geq 2\text{.}\) Then the sequence \(E_1 \setminus D_1\text{,}\) \(E_2 \setminus D_2\text{,}\) \(\ldots\) is a distinct sequence of subsets whose union equals \(\displaystyle \bigcup_{k=1}^{\infty} E_k\)
    🔗
    Thus it follows from countable addivitity and monotonicity that
    \begin{align*} \mu \left( \bigcup_{k=1}^{\infty} E_k \right) \amp = \mu \left( \bigcup_{k=1}^{\infty} E_k \setminus D_k \right)\\ \amp = \sum_{k=1}^{\infty} E_k \setminus D_k\\ \amp \leq \sum_{k=1}^{\infty} E_k \end{align*}
    🔗
    🔗

    Theorem 39. Measure of an Increasing Union.

    Suppose \((X,S,\mu)\) is a measure space and \(E_1 \subset E_2 \subset \ldots\) is an increasing sequence of sets in \(S\text{.}\) Then
    \begin{equation*} \mu \left( \bigcup_{k=1}^{\infty} E_k\right) = \lim_{k\to \infty} \mu(E_k) \end{equation*}
    🔗
    🔗

    Proof.

    If \(\mu(E_k) = \infty\) for some \(k \in \mathbf{N}\) then both sides of the above equation are equal to \(\infty\) and theorem is true. Thus we may suppose that \(\mu(E_k) < \infty\) for all \(k\text{.}\)
    🔗
    Our strategy is to rewrite the left hand side as a disjoint union so that we can apply countable additivity. Let \(E_0 = \emptyset\text{.}\) Then
    \begin{equation*} \bigcup_{k=1}^{\infty} E_k = \bigcup_{j=1} E_j \setminus E_{j-1}, \end{equation*}
    and the right side is a disjoint union.
    🔗
    Hence by countable additivity of measure,
    \begin{equation*} \mu \left( \bigcup_{k=1}^{\infty} E_k \right) = \sum_{j=1}^{\infty} \mu( E_j \setminus E_{j-1}). \end{equation*}
    🔗
    It follows from the measure of set difference that
    \begin{align*} \mu \left( \bigcup_{k=1}^{\infty} E_k \right) \amp = \sum_{j=1}^{\infty} \mu( E_j \setminus E_{j-1}) \\ \amp = \lim_{k\to \infty} \sum_{j=1}^{k} \mu( E_j \setminus E_{j-1})\\ \amp = \lim_{k\to \infty} \sum_{j=1}^{k} \mu( E_j) -\mu(E_{j-1})\\ \amp = \lim_{k\to \infty} \mu(E_k). \end{align*}
    🔗
    🔗
    Measures also behave as expected with respect to decreasing intersections, provided that the sets under consideration have finite measures.
    🔗

    Theorem 40. Measure of a Decreasing Intersection.

    Suppose \((X,S,\mu)\) is a measure space and \(E_1 \supseteq E_2 \supseteq \ldots\) is a decreasing sequence of sets in \(S\) with \(\mu(E_1) < \infty\text{.}\) Then
    \begin{equation*} \mu \left( \bigcap_{k=1}^{\infty} E_k \right) = \lim_{k\to \infty} \mu(E_k). \end{equation*}
    🔗
    🔗

    Proof.

    Our strategy is to rewrite the left hand side as an increasing union so that we can apply the previous result. It follows from De Morgan’s laws that
    \begin{equation*} E_1 \setminus \bigcap_{k=1}^{\infty} E_k = \bigcup_{k=1}^{\infty} E_1 \setminus E_k. \end{equation*}
    🔗
    We note that \(E_1 \setminus E_1 \subseteq E_1 \setminus E_2 \subseteq E_1 \setminus E_3 \subseteq\) is an increasing sequence of sets in \(S\text{.}\)
    🔗
    Hence by our previous result,
    \begin{equation*} \mu \left( E_1 \setminus \bigcap_{k=1}^{\infty} E_k \right) = \mu \left( \bigcup_{k=1}^{\infty} E_1 \setminus E_k \right) = \lim_{k\to \infty} \mu(E_1 \setminus E_k). \end{equation*}
    🔗
    Using the formula for the measure of set difference, we can rewrite this as
    \begin{equation*} \mu(E_1) - \mu \left( \bigcap_{k=1}^{\infty} E_k \right) = \mu(E_1) - \lim_{k\to \infty} \mu(E_k) \end{equation*}
    and the theorem follows by subtracting \(\mu(E_1)\) from both sides and dividing by \(-1\text{.}\)
    🔗
    🔗

    Theorem 41. Measure of a Union.

    Suppose \((X,S,\mu)\) is a measure space and \(D,E \in S\) with \(\mu(D \cap E) < \infty\text{.}\) Then
    \begin{equation*} \mu(D \cup E) = \mu(E) + \mu(D) - \mu(D \cap E). \end{equation*}
    🔗
    🔗
    If \((X,S,\mu)\) is a probability space and \(D\) and \(E\) are events, then the above equation is just the formula for the probability of a disjunction.
    \begin{equation*} P(D \text{ or } E) = P(D) + P(E) - P(D \text{ and } E). \end{equation*}
    🔗
    If \(E\) and \(D\) are mutually exclusive events (meaning \(D \cap E = \emptyset\)) then
    \begin{equation*} P(D \text{ or } E) = P(D) + P(E). \end{equation*}
    🔗

    Proof.

    Our strategy is to rewrite the left hand side as a disjoint union and apply countable additivity.
    \begin{equation*} D \cup E = (D \setminus (D\cap E)) \cup (E \setminus (D\cap E)) \cup (D\cap E) \end{equation*}
    🔗
    Since the right hand side is a disjoint union we have
    \begin{align*} \mu( D \cup E) \amp = \mu(D \setminus (D\cap E)) + \mu(E \setminus (D\cap E)) + \mu(D\cap E)\\ \amp =\mu(D) - \mu(D\cap E) + \mu(E) - \mu(D\cap E) + \mu(D\cap E)\\ \amp =\mu(D) + \mu(E) - \mu(D\cap E). \end{align*}
    🔗
