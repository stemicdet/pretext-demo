    Section Week 5: Lebesgue Measure (2D)

    Subsection Additivity of Outer Measure on Borel Sets

    Recall that outer measure is not additive on all subsets of \(\mathbf{R}\text{.}\) This means that there exists disjoint subsets \(A\) and \(B\) of \(\mathbf{R}\) such that \(|A\cup B| \neq |A|+|B|\text{.}\)
    🔗
    Thus outer measure defined on all subsets of \(\mathbf{R}\) is not actually a measure. However, we will show that outer measure is a bonafide measure when restricted to Borel subsets of \(\mathbf{R}\text{.}\)
    🔗
    This restricted outer measure, which is called Lebesgue measure, is the generalization of the concept of the length of an interval that we have been seeking.
    🔗
    We start our proof of the additivity of outer measure on Borel sets by showing that outer measure is additive when one of the sets is open.
    🔗

    Theorem 42. Additivity of Outer Measure if One of the Sets is Open.

    Suppose \(A\) and \(G\) are disjoint subsets of \(\mathbf{R}\) and \(G\) is open. Then \(|A \cup G| = |A| + |G|\text{.}\)
    🔗
    🔗

    Proof.

    If \(|G| = \infty\) then both sides are equal, so we may suppose that \(|G| < \infty\text{.}\)
    🔗
    By subadditivity of outer measure we know that \(|A \cup G| \leq |A| + |G|\text{.}\) Hence we just need to prove the other direction.
    🔗
    First suppose that \(G\) is the open interval \((a,b)\) with \(a < b\text{.}\) We may also suppose that \(a,b \notin A\) because removing two points from \(A\) does not change its outer measure.
    🔗
    Recall that we defined the outer measure of a set by taking the infimum over all open covers of the set. So let \(I_1, I_2, \ldots\) be a sequence of open intervals whose union contains \(A \cup G\text{.}\)
    🔗
    For each \(N \in \mathbf{N}\) let \(J_n = I_n \cap (\infty,a)\text{,}\) \(K_n = I_n \cap (a,b)\text{,}\) and \(L_n = I_n \cap (b,\infty)\text{.}\) Hence \(\ell(I_n) = \ell(J_n) + \ell(K_n) + \ell(J_n)\text{.}\)
    🔗
    Since \(A\) and \(G\) are disjoint, \(K_1, K_2, \ldots\) is a sequence of open intervals that cover \(G\) and \(J_1, L_1, J_2, L_2, \ldots\) is a sequence of open intervals that cover \(A\text{.}\) Thus
    \begin{align*} \sum_{n=1}^{\infty}\ell(I_n) \amp = \sum_{n=1}^{\infty} \ell(J_n) + \ell (L_n) + \sum_{n=1}^{\infty} \ell (K_n) \\ \amp \geq |A|+|G| \end{align*}
    Thus \(|A\cup G| \geq |A| + |G|\) and hence \(|A \cup G| = |A|+|G|\) in this special case.
    🔗
    By Induction it follows that if \(G\) is a union of finitely many disjoint intervals that are all disjoint from \(A\text{,}\) then \(|A \cup G| = |A| + |G|\text{.}\)
    🔗
    Finally suppose that \(G\) is an arbitrary open set that is disjoint from \(A\text{.}\) Then \(G = \cup_{n=1}^{\infty} I_n\) for some sequence of disjoint open intervals \(I_1, I_2, \ldots\) each of which is disjoint from \(A\text{.}\)
    🔗
    Hence for each \(m \in \mathbf{N}\) we have
    \begin{align*} |A \cup G| \amp \geq \left|A \cup \bigcup_{n=1}^m I_n\right| \\ \amp = |A| + \sum_{n=1}^m \ell(I_n) \end{align*}
    🔗
    Thus
    \begin{align*} |A \cup G| \amp \geq |A| + \sum_{n=1}^m \ell(I_n) \\ \amp \geq |A|+|G| \end{align*}
    Thus \(|A \cup G| = |A| + |G|\) and the proof is complete.
    🔗
    🔗
    Next we show that outer measure is additive if one of the two sets is closed.
    🔗

    Theorem 43. Additivity of Outer Measure if One of the Sets is Closed.

    Suppose \(A\) and \(F\) are disjoint subsets of \(\mathbf{R}\) and \(F\) is closed. Then
    \begin{equation*} |A \cup F| \leq |A| + |F|. \end{equation*}
    🔗
    🔗

    Proof.

    Suppose \(I_1, I_2, \ldots\) is a sequence of open intervals whose union contains \(A \cup F\) and let
    \begin{equation*} G = \bigcup_{k=1}^{\infty} I_k \end{equation*}
    🔗
    Then \(G\) is an open set and \(A \cup F \subseteq G\text{.}\) Hence \(A \subseteq G \setminus F\text{,}\) which is open because it is an open set minus a closed set.
    🔗
    If we write \(G\) as \(G = F \cup G \setminus F\text{,}\) then \(G\) is a disjoint union in which one set is open. Hence the previous theorem applies and \(|G| = |F| + |G \setminus F|\text{.}\)
    🔗
    Moreover, \(|A| \leq |G \setminus F|\text{.}\) Hence
    \begin{align*} |A|+|F| \leq |G \setminus F| + |F| \amp = |G|\\ \amp \leq \sum_{k=1}^{\infty} \ell(I_k) \end{align*}
    🔗
    Since \(\displaystyle \bigcup_{k=1}^{\infty} I_k\) is a cover of \(A \cup F\) it follows from taking the infimum over all such covers that
    \begin{equation*} |A| + |F| \leq |A \cup F| \end{equation*}
    🔗
    Since it follows from countable subadditivity that \(|A \cup F| \leq |A| + |F|\text{,}\) we have that \(|A| + |F| = |A \cup F|\) and the theorem is proven.
    🔗
    🔗
    The Borel \(\sigma\)-algebra is the smallest \(\sigma\)-algebra that contains all the open sets. In general we cannot represent Borel sets by a finite combination of countable unions and intersections; however, we can nicely approximated Borel sets by closed sets.
    🔗

    Theorem 44. Approximation of Borel Sets from Below by Closed Sets.

    Suppose \(B \subseteq \mathbf{R}\) is a Borel set. Then for every \(\epsilon>0\text{,}\) there exists a closed set \(F \subseteq B\) such that \(|B \setminus F| < \epsilon\text{.}\)
    🔗
    🔗

    Proof.

    Let \(L = \{D \subseteq \mathbf{R}: \text{ for every } \epsilon>0 \text{ there exists a closed set } F \subseteq \mathbf{R} \text{ such that } |D \setminus F| < \epsilon\}\text{.}\) Note that \(L\) contains all closed subsets of \(\mathbf{R}\text{.}\) We will show that \(L\) is a \(\sigma\)-algebra. Since \(L\) is a \(\sigma\)-algebra that contains all closed subsets of \(\mathbf{R}\) it must also contain all the open subsets of \(\mathbf{R}\) and thus contains all Borel sets.
    🔗
    First, \(\emptyset \in L\) since \(\emptyset\) is a closed set.
    🔗
    Before we prove that \(L\) is closed under compliments, we will prove that \(L\) is closed under countable intersections. Suppose that \(D_1, D_2, \ldots \) is a sequence of elements in \(L\text{.}\) Let \(\epsilon>0\) be arbitrary. Then for each \(k \in \mathbf{N}\text{,}\) there exists a closed set \(F_k\) such that
    \begin{equation*} F_k \subseteq D_k \text{ and } |D_k \setminus F_k| < \frac{\epsilon}{2^k} \end{equation*}
    🔗
    In addition
    \begin{equation*} \left( \bigcap_{k=1}^{\infty} D_k \right) \setminus \left( \bigcap_{k=1}^{\infty} F_k \right) \subseteq \left( \bigcap_{k=1}^{\infty} D_k \setminus F_k \right) \end{equation*}
    🔗
    Hence by monotonicity and subadditivity
    \begin{align*} \left| \left( \bigcap_{k=1}^{\infty} D_k \right) \setminus \left( \bigcap_{k=1}^{\infty} F_k \right) \right| \amp \leq \left| \left( \bigcap_{k=1}^{\infty} D_k \setminus F_k \right)\right|\\ \\ \amp \leq \sum_{k=1}^{\infty} \frac{\epsilon}{2^k} \leq \epsilon. \end{align*}
    🔗
    Thus \(\displaystyle \bigcap_{k=1}^{\infty} D_k \in L\text{.}\) So \(L\) is closed under countable intersections.
    🔗
    Now we want to show that \(L\) is closed under compliments. That is, given \(D \in L\) we want to show that \(\mathbf{R}\setminus D\) is also a subset of \(L\text{.}\) First suppose that \(|D| < \infty\text{.}\) Let \(\epsilon>0\) be arbitrary. Then there exists a closed set \(F \subseteq D\) such that \(|D \setminus F| < \frac{\epsilon}{2}\text{.}\) It follows from the definition of outer measure that there exists an open set \(G\) such that \(D \subseteq G\) and \(|G| < |D| + \frac{\epsilon}{2}\text{.}\)
    🔗
    Then \(\mathbf{R} \setminus G\) is a closed subset of \(\mathbf{R} \setminus D\) and
    \begin{equation*} (\mathbf{R}\setminus D) \setminus (\mathbf{R}\setminus G) = G \setminus D \subseteq G \setminus F \end{equation*}
    🔗
    Thus by subadditivity,
    \begin{equation*} |(\mathbf{R}\setminus D) \setminus (\mathbf{R}\setminus G)| \leq |G \setminus F| \end{equation*}
    🔗
    Since \(G = G\setminus F \cup F\) and these are disjoint sets with \(F\) closed it follows from additivity of outer measure with one closed set that \(|G| = |G\setminus F| + |F|\text{.}\) Thus \(|G\setminus F| = |G| - |F|\text{.}\)
    🔗
    Thus
    \begin{align*} |(\mathbf{R}\setminus D) \setminus (\mathbf{R}\setminus G)| \amp \leq |G|-|F|\\ \amp =|G|-|D| + |D|-|F| \end{align*}
    🔗
    Since \(D = D\setminus F \cup F\) and these are disjoint sets with \(F\) closed it follows from additivity of outer measure with one closed set that \(|D| = |D\setminus F| + |F|\text{.}\) Thus \(|D\setminus F| = |D| - |F|\text{.}\)
    🔗
    Hence
    \begin{align*} |(\mathbf{R}\setminus D) \setminus (\mathbf{R}\setminus G)| \amp =|G|-|D| + |D|-|F| \\ \amp < \frac{\epsilon}{2} + |D\setminus F| \\ \amp < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon. \end{align*}
    🔗
    Since we have that \(|(\mathbf{R}\setminus D) \setminus (\mathbf{R}\setminus G)| < \epsilon\) and \(R \setminus G\) is closed, this means that \(\mathbf{R}\setminus D \in L\text{.}\)
    🔗
    For the case that \(|D| = \infty\text{,}\) let \(D_k = D \cap [-k,k]\text{.}\) Then \(D_k \in L\) since \([-k,k]\) is a closed set and belongs to \(L\) and as a \(\sigma\)-algebra, \(L\) is closed under finite intersections. Since \(|D_k| \leq 2k\) and \(D_k \in L\text{,}\) it follows that \(\mathbf{R}\setminus D_k \in L\text{.}\)
    🔗
    Because \(\displaystyle D = \bigcup_{k=1}^{\infty} D_k\) it follows from De Morgan’s Laws that
    \begin{equation*} \mathbf{R}\setminus D = \bigcap_{k=1}^{\infty} \mathbf{R} \setminus D_k. \end{equation*}
    🔗
    Since \(L\) is closed under countable intersection, this implies that \(\mathbf{R} \setminus D \in L\text{.}\) Thus \(L\) is closed under compliments.
    🔗
    Finally we show that \(L\) is closed under countable unions. Let \(D_1, D_2, \ldots\) be a sequence of subsets in \(L\text{.}\) Then it follows from DeMorgan’s laws that
    \begin{equation*} \mathbf{R}\setminus \bigcup_{k=1}^{\infty} D_k = \bigcap_{k=1}^{\infty} \mathbf{R} \setminus D_k. \end{equation*}
    🔗
    Since \(L\) is closed under countable intersection, this implies that \(\displaystyle \mathbf{R} \setminus \bigcup_{k=1}^{\infty} D_k \in L\text{.}\) Since \(L\) is closed under compliments this means that \(\displaystyle \bigcup_{k=1}^{\infty} D_k \in L\text{.}\) Thus \(L\) is closed under countable unions and hence \(L\) is a \(\sigma\)-algebra that contains all Borel subsets of \(\mathbf{R}\text{.}\)
    🔗
    🔗
    Now we can prove that the outer measure is additive provided that one of the sets is a Borel set.
    🔗

    Theorem 45. Additivity of Outer Measure if One Set is a Borel Set.

    Suppose that \(A\) and \(B\) are disjoint subsets of \(\mathbf{R}\) and \(B\) is a Borel set. Then \(|A \cup B| = |A| + |B|\text{.}\)
    🔗
    🔗

    Proof.

    Let \(\epsilon>0\) be arbitrary and let \(F\) be a closed set such that \(F \subseteq B\) and \(|B \setminus F| < \epsilon\text{.}\) Then it follows from monotonicity and additivity of outer measure when one set is closed that
    \begin{align*} |A \cup B| \amp |A \cup F| \\ \amp = |A| + |F|\\ \amp = |A|+ |B| - |B \setminus F| \\ \amp \geq |A| + |B| - \epsilon \end{align*}
    🔗
    Because this inequality holds for all \(\epsilon>0\) we have that \(|A \cup B| \geq |A|+|B|\) and hence \(|A \cup B| = |A| + |B|\text{.}\)
    🔗
    🔗
    As a corollary, we can show that there are subsets of \(\mathbf{R}\) that are not Borel sets.
    🔗

    Corollary 46. Existence of a Subset of \(\mathbf{R}\)that is Not a Borel Set.

    There exists a subset \(B\) of \(\mathbf{R}\) that is not a Borel set.
    🔗
    🔗

    Proof.

    When we proved that outer measure is not additive in general, we constructed disjoint sets \(A\) and \(B\) with \(|A| + |B| \neq |A \cup B|\text{.}\) By the previous theorem this means that neither \(A\) nor \(B\) can be Borel sets.
    🔗
    🔗
    We can finally prove that outer measure restricted to Borel sets is a bonafide measure.
    🔗

    Theorem 47. Outer Measure is a Measure on Borel Sets.

    Outer measure is a measure on \((\mathbf{R}, B)\) where \(B\) is the set of Borel subsets of \(\mathbf{R}\text{.}\)
    🔗
    🔗

    Proof.

    We need to show that outer measure on Borel sets satisfies countable additivity. Let \(B_1, B_2, \ldots\) be a sequence of Borel sets. Then it follows from additivity of outer measure on Borel sets that
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} B_k\right| \geq \left| \bigcup_{k=1}^{n} B_k\right| = \sum_{k=1}^n |B_k|. \end{equation*}
    🔗
    Thus by taking the limit as \(n \to \infty\) we have that
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} B_k\right| \geq \sum_{k=1}^{\infty} |B_k|. \end{equation*}
    🔗
    Since the other direction of the inequality follows from countable subadditivity we have that
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} B_k\right| = \sum_{k=1}^{\infty} |B_k|. \end{equation*}
    and thus outer measure on Borel sets is countably additive and hence is a measure.
    🔗
    🔗
    We are now in position to define Lebesgue measure.
    🔗

    Definition 48. Lebesgue Measure.

    Lebesgue Measure is the measure on \((\mathbf{R}, B)\) where \(B\) is the \(\sigma\)-algebra of Borel subsets of \(\mathbf{R}\text{,}\) that assigns to each Borel set its outer measure.
    🔗
    🔗
    Lebesgue measure is the same thing as outer measure except that it is only applied to Borel sets. Unlike outer measure, Lebesgue measure is truly a measure. We have shown that outer measure restricted to Borel sets is a bonafide measure; however, as it turns out we can do a little better. Outer measure is still a measure if restricted to a larger collection of functions called Lebesgue measurable sets.
    🔗
    🔗

    Subsection Lebesgue Measurable Sets

    Definition 49.

    A set \(A \subseteq \mathbf{R}\) is called Lebesgue measurable if there exists a Borel set \(B \subseteq A\) such that \(|A \setminus B| =0\text{.}\)
    🔗
    🔗
    Every Borel set is a Lebesgue measurable set; however, there are Lebesgue measurable sets that are not Borel sets, but it is rather difficult to come with up an example of one. However, it can be shown that the cardinality of the collection of Borel subsets of \(\mathbf{R}\) is equal to the cardinality of the real numbers, but the cardinality of the Lebesgue measurable sets is equal to the cardinality of the power set of the real numbers which is strictly greater. Thus there are vastly more Lebesgue measurable sets than Borel sets.
    🔗

    Theorem 50. Equivalences for Being a Lebesgue Measurable Set.

    Suppose \(A \subseteq \mathbf{R}\text{.}\) Then the following are equivalent:
    1. \(A\) is Lebesgue measurable.
      🔗
      🔗
    2. For every \(\epsilon>0\) there exists a closed set \(F \subseteq A\) with \(|A \setminus F| < \epsilon\text{.}\)
      🔗
      🔗
    3. There exist closed sets \(F_1, F_2, \ldots\) contained in \(A\) such that \(\displaystyle |A \setminus \bigcup_{k=1}^{\infty} F_k| = 0\text{.}\)
      🔗
      🔗
    4. There exists a Borel set \(B \subseteq A\) such that \(|A\setminus B| = 0\text{.}\)
      🔗
      🔗
    5. For every \(\epsilon>0\) there exists an open set \(G \supseteq A\) with \(|G \setminus A| < \epsilon\text{.}\)
      🔗
      🔗
    6. There exist open sets \(G_1, G_2, \ldots\) containing \(A\) such that \(\displaystyle \left| \left(\bigcap_{k=1}^{\infty} G_k\right) \setminus A\right| = 0\)
      🔗
      🔗
    7. There exists a Borel set \(B \supseteq A\) such that \(|B \setminus A| = 0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    (d) is the definition of Lebesgue measure so clearly (a) and (d) are equivalent. Thus we can prove the Theorem by proving the following chain of implications: (b) implies (c) implies (d) implies \(\ldots\) implies (g) implies (b). Since a lot of these implications are similar, we will just show one of them. We will show that (b) implies (c).
    🔗
    Suppose that (b) is true; that is, for every \(\epsilon>0\) there exists a closed set \(F \subseteq A\) with \(|A \setminus F| < \epsilon\text{.}\)
    🔗
    Thus for each \(n \in \mathbf{N}\) there exists a closed set \(F_n \subseteq A\) with \(|A \setminus F_n| < \frac{1}{n}\text{.}\) Since
    \begin{equation*} A \setminus \bigcup_{k=1}^{\infty} F_k \subseteq A \setminus F_n \end{equation*}
    for each \(n \in \mathbf{N}\) it follows from subadditivity of outer measure that
    \begin{equation*} \left| A \setminus \bigcup_{k=1}^{\infty} F_k \right| \leq |A \setminus F_n| < \frac{1}{n}. \end{equation*}
    🔗
    Thus by letting \(n \to \infty\) we obtain that
    \begin{equation*} \left| A \setminus \bigcup_{k=1}^{\infty} F_k \right| = 0. \end{equation*}
    🔗
    Thus we have shown that (b) implies (c) in our chain of implications. The other implications are similarly proved.
    🔗
    🔗
    Now we can show that outer measure restricted to Lebesgue measurable sets is still a measure.
    🔗

    Theorem 51. Outer Measure is a Measure on Lebesgue Integrable Sets.

    1. The set \(L\) of Lebesgue measurable subsets of \(\mathbf{R}\) is a \(\sigma\)-algebra on \(\mathbf{R}\text{.}\)
      🔗
      🔗
    2. Outer measure is a measure on \((\mathbf{R},L)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    We already showed that \(L\) is a \(\sigma\)-algebra so it remains to show that outer measure on \((\mathbf{R}, L)\) is a measure. To do this we must show countable additivity of disjoint sets.
    🔗
    Let \(A_1, A_2, \ldots\) be a disjoint sequence of Lebesgue measurable sets. By the definition of Lebesgue measurable measurable sets, for each \(k\text{,}\) there exists a Borel set \(B_k \subseteq A_k\) such that \(|A_k \setminus B_k| = 0\text{.}\)
    🔗
    Because outer measure on Borel sets is countably additive, we have that
    \begin{align*} \left| \bigcup_{k=1}^{\infty} A_k \right| \amp \geq \left| \bigcup_{k=1}^{\infty} B_k \right| \\ \amp = \sum_{k=1}^{\infty} |B_k|. \end{align*}
    🔗
    Now it follows from the subadditivity of outer measure that
    \begin{align*} |A_k| \amp = |A_k \setminus B_k \cup B_k| \\ \amp \leq |A_k\setminus B_k| + |B_k| \\ \amp = |B_k| \end{align*}
    since \(|A_k \setminus B_k| = 0\text{.}\)
    🔗
    Since outer measure is monotone and \(B_k \subseteq A_k\text{,}\) \(|B_k| \leq |A_k|\) it follows that \(|B_k| = |A_k|\text{.}\) Hence
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} A_k \right| \geq \sum_{k=1}^n |A_k|. \end{equation*}
    🔗
    By subadditivity of outer measure we have that
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} A_k \right| \leq \sum_{k=1}^n |A_k|, \end{equation*}
    and hence
    \begin{equation*} \left| \bigcup_{k=1}^{\infty} A_k \right| = \sum_{k=1}^n |A_k|. \end{equation*}
    🔗
    Since outer measure is countably additive on Lebesgue measurable sets, outer measure restricted to Lebesgue measurable sets is a measure.
    🔗
    🔗
    If \(A\) is a set with outer measure \(0\text{,}\) then \(A\) must be a Lebesgue measurable set since \(\emptyset\) is a Borel set and \(|A \setminus \emptyset| = 0\text{.}\)
    🔗
    Thus the set of Lebesgue measurable sets is the smallest Borel algebra containing both all open subsets of \(\mathbf{R}\) and all subsets of \(\mathbf{R}\) with outer measure \(0\text{.}\)
    🔗
    Because outer measure is not additive on all subsets of \(\mathbf{R}\) there are subsets of \(\mathbf{R}\) that are not Lebesgue measurable sets.
    🔗

    Definition 52. Lebesgue Measure.

    Lebesgue measure is the measure on \((\mathbf{R}, L)\) where \(L\) is the \(\sigma\)-algebra of Lebesgue measurable subsets of \(\mathbf{R}\text{,}\) that assigns to each Lebesgue measurable set its outer measure.
    🔗
    🔗
    We have two different definitions for Lebesgue measure which only differ on the domain of the measure-- is it the \(\sigma\)-algebra of Borel sets or Lebesgue measurable sets?
    🔗
    Usually it doesn’t matter whether you use Borel sets or Lebesgue measurable sets. I will specify whether Lebesgue measure refers to Borel sets or Lebesgue measurable sets, unless it is irrelevant.
    🔗
    🔗

    Subsection The Cantor Set and Cantor Function

    We might hope that Lebesgue measurable sets would behave nicely with respect to continuous functions; in other words, if \(A\) is a Lebesgue measurable set and \(f: A \to \mathbf{R}\) is a continuous function then \(f(A)\) would also be a Lebesgue measurable set.
    🔗
    Unfortunately, this is not the case as we will demonstrate by constructing a counterexample. For this we will need to use the Cantor set.
    🔗
    Recall that the Cantor set is constructed by starting with the interval \([0,1]\) and successively removing the middle thirds from each interval.
    🔗

    Definition 53. Cantor Set.

    The Cantor Set \(C\) is \(\displaystyle [0,1] \setminus \cup_{n=1}^{\infty} G_n\) where \(G_1 = (1/3, 2/3)\) and \(G_n\) for \(n > 1\) is the union of the middle third open intervals in the intervals of \(\displaystyle [0,1] \setminus \cup_{j=1}^{n-1} G_j\text{.}\)
    🔗
    🔗
    The Cantor set can also be represented using Ternary (Base 3) expansions. In Ternary, place values represent powers of 3: threes, nines, twenty-sevens, \(\frac{1}{3}\text{,}\) \(\frac{1}{9}\text{,}\) \(\ldots\text{.}\)
    🔗
    Suppose a number has Ternary expansion \(0.a_1 a_2 a_3 \ldots\text{.}\) where \(a_n = 0\text{,}\) \(1\text{,}\) or \(2\text{.}\) The value of \(a_1\) tells which third of the interval \([0,1]\) the point belongs to.
    🔗
    If \(a_1 = 0\text{,}\) the point is in the left third of \([0,1]\text{,}\) if \(a_1 = 1\text{,}\) the point is in the middle third of \([0,1]\text{,}\) and if \(a_1 = 2\text{,}\) the point is in the right third of \([0,1]\text{.}\)
    🔗
    This means that any number whose Ternary expansion has \(a_1=1\) belongs to the middle third interval and is removed in the first step of constructing the Cantor set.
    🔗
    Likewise the value of \(a_2\) tells which third of the interval \([0,\frac{1}{3}]\) or \([\frac{2}{3},1]\) the point belongs to, with \(a_2 = 1\) corresponding to the middle third of that interval.
    🔗
    Thus any number whose Ternary expansion contains a \(1\) in it will be in the middle third of some interval and will be removed in the construction of the Cantor set. Thus a point is in the Cantor set if and only if its Ternary expansion only contains the digits \(0\) or \(2\text{.}\)
    🔗

    Theorem 54. Properties of the Cantor Set.

    1. The Cantor set is a closed subset of \(\mathbf{R}\text{.}\)
      🔗
      🔗
    2. The Cantor set has Lebesgue measure \(0\text{.}\)
      🔗
      🔗
    3. The Cantor set contains no intervals with more than one element.
      🔗
      🔗
    🔗
    🔗

    Proof.

    (a) The compliment of the Cantor set is a countable union of open intervals, so it is an open set. Thus the Cantor set must be closed.
    🔗
    (b) In MTH 527 we proved that the compliment of the Cantor set has length \(1\text{,}\) hence it has Lebesgue measure \(1\) and thus the Cantor set has Lebesgue measure \(0\text{.}\)
    🔗
    (c) Since an interval with at least two elements has positive measure, it follows from (b) that the Cantor set can’t contain intervals with more than one element.
    🔗
    🔗
    We will refer to the following function several times throughout this course.
    🔗

    Definition 55. The Cantor Function.

    The Cantor function or Cantor-Lebesgue Function \(\Lambda: [0,1] \to [0,1]\) is defined by converting base 3 representations into base 2 representations as follows.
    🔗
    • If \(x\) belongs to the Cantor set then \(\Lambda(x)\) is computed from the unique base 3 representation of \(x\) consisting only of \(0\)’s and \(2\)’s by replacing all \(2\)’s in the expansion by \(1\)’s and interpreting the resulting string as a base 2 number.
      🔗
      🔗
    • If \(x\) does not belong to the Cantor set, then \(\Lambda(x)\) is computed by truncating after the first \(1\text{,}\) replacing each \(2\) before the first \(1\) with \(1\) and interpreting the resulting string as a base 2 number.
      🔗
      🔗
    🔗
    As an example, suppose \(x = \frac{8}{9}\text{,}\) which is an element of the Cantor set. Since \(\frac{8}{9} = \frac{2}{3}+ \frac{2}{9}\text{,}\) the base 3 representation of \(\frac{8}{9}\) is \(0.22_3\text{.}\) Hence \(\Lambda(\frac{8}{9}) = 0.11_2 = \frac{1}{2}+ \frac{1}{4} = \frac{3}{4}\text{.}\)
    🔗
    For another example, suppose \(x = \frac{1}{3}\text{,}\) which is also an element of the Cantor set. One base 3 representation of \(\frac{1}{3}\) is \(0.1_3\text{,}\) but we don’t want to use this because it contains a \(1\text{.}\) Instead we note that the infinite series \(\frac{2}{9} + \frac{2}{27} + \frac{2}{81} + \ldots = \frac{1}{3}\text{.}\) So another base 3 representation of \(\frac{1}{3}\) is \(0.0222\ldots_3\) and this representation does not contain a \(1\text{.}\) Hence \(\Lambda(\frac{1}{3}) = 0.0111\ldots_2 = \frac{1}{4}+ \frac{1}{16}+ \frac{1}{64}+ \ldots = \frac{1}{2}\text{.}\)
    🔗
    For an example involving a number outside the Cantor set, suppose \(x = \frac{1}{2}\text{,}\) which is not an element of the Cantor set since it is removed during the first iteration. Since \(\frac{1}{2} = \frac{1}{3}+ \frac{1}{9} + \frac{1}{27}+ \ldots\text{,}\) the base 3 representation of \(\frac{1}{2}\) is \(0.1111\ldots_3\text{.}\) Since \(\frac{1}{2}\) is not an element of the Cantor set, we truncate everything after the first \(1\) to get \(0.1_3\text{.}\) There are no \(2\)’s to replace so we interpret this as the base \(2\) number \(0.1_2 = \frac{1}{2}\text{.}\) Thus \(\Lambda(\frac{1}{2}) = \frac{1}{2}\text{.}\)
    🔗
    In fact, for every \(x \in (\frac{1}{3}, \frac{2}{3})\text{,}\) \(\Lambda(x) = \frac{1}{2}\text{.}\) This is because the base 3 representation of every number in \((\frac{1}{3}, \frac{2}{3})\) starts with \(0.1\) and thus is truncated to \(0.1_3\text{,}\) just like with \(\frac{1}{2}\text{.}\)
    🔗
    As a final example, suppose \(x \in (\frac{7}{9}, \frac{8}{9})\text{.}\) For every number in this interval the base 3 representation starts with \(0.21\text{.}\) Truncating after the first \(1\) gives \(0.21_3\) and replacing the \(2\) with a \(1\) and interpreting the result as a base 2 number gives \(0.11_2 = \frac{1}{2}+ \frac{1}{4} = \frac{3}{4}\text{.}\) Thus \(\Lambda(x) = \frac{3}{4}\) for every \(x \in (\frac{7}{9}, \frac{8}{9})\text{.}\)
    🔗

    Theorem 57. Properties of the Cantor Function.

    The Cantor function \(\Lambda\) is a continuous, increasing function from \([0,1]\) onto \([0,1]\text{.}\) Furthermore \(\Lambda(C) = [0,1]\text{,}\) where \(C\) denotes the Cantor set.
    🔗
    🔗

    Proof.

    We’ll first show that \(\Lambda(C) = [0,1]\text{.}\) To do this, let \(y \in [0,1]\text{.}\) Then \(y\) has a base 2 representation consisting only of \(0\)’s and \(1\)’s. By replacing the \(1\)’s with \(2\)’s, we end up with a base 3 representation that consists only of \(0\)’s and \(2\)’s and thus represents an element of the Cantor set. If we denote this element by \(x\) then \(\Lambda(x) = y\text{.}\) Thus \(y \in \Lambda(C)\) and hence \(\Lambda(C) = [0,1]\text{.}\)
    🔗
    To show that the Cantor function is increasing, suppose \(x_1 < x_2\) and that \(x_1\) has base 3 representation \(a_1a_2a_3\ldots\) and \(x_2\) has base 3 representation \(b_1b_2b_3\ldots\text{.}\) Then at some point their base 3 representations first differ and \(a_n < b_n\text{.}\) The only possibilities are that \(a_n = 0\) and \(b_n = 1\) or \(2\) or that \(a_n = 1\) and \(b_n = 2\text{.}\) Either way, when the Cantor function is applied and 2’s are replaced by 1’s \(a_n \leq b_n\) and hence \(\Lambda(x_1) \leq \Lambda(x_2)\text{,}\) so the Cantor function is increasing.
    🔗
    To show that the Cantor function is continuous, we first recall that an increasing function can only have jump discontinuities. Thus if the Cantor function is discontinuous at \(c\) then it must have a jump discontinuity there and hence
    \begin{equation*} \lim_{x \to c^-} \Lambda(x) < \lim_{x\to c^+} \Lambda(x). \end{equation*}
    But this means that the Cantor function fails to attain all values between \(\displaystyle \lim_{x \to c^-} \Lambda(x)\) and \(\displaystyle \lim_{x \to c^+} \Lambda(x)\text{,}\) which contradicts the fact that the range of the Cantor function is all \([0,1]\text{.}\) Thus the Cantor function must be continuous on \([0,1]\text{.}\)
    🔗
    🔗
    We can use the Cantor function to give a short proof that the Cantor set is uncountable.
    🔗

    Theorem 58. The Cantor Set is Uncountable.

    The Cantor set is uncountable.
    🔗
    🔗

    Proof.

    If the Cantor set \(C\) was countable then \(\Lambda(C)\) would also be countable since \(\Lambda\) is a bijection from \(C\) to \(\Lambda(C)\text{,}\) but since \(\Lambda(C) = [0,1]\) which is uncountable, the Cantor set must also be uncountable.
    🔗
    🔗
    Lastly, we use the Cantor function to show that even a continuous function can map a set of measure \(0\) to a non-measurable set.
    🔗

    Theorem 59. Continuous Image of a Lebesgue Measurable Set Can Be Non-Measurable.

    There exists a Lebesgue measurable set \(A \subseteq [0,1]\) such that \(|A| = 0\) and \(\Lambda(A)\) is not a measurable set.
    🔗
    🔗

    Proof.

    Let \(E\) be a non-measurable subset of \([0,1]\) and let \(A = C \cap \Lambda^{-1}(E)\text{.}\) Then \(|A| \leq |C| = 0\) by monotonicity. Hence \(A\) is a Lebesgue measurable set because every set with measure \(0\) is Lebesgue measurable. Since \(\Lambda(C) = [0,1]\text{,}\) \(\Lambda(A) = E\) which is not a measurable set. Thus \(A\) is a Lebesgue measurable set whose image under \(\Lambda\) is not Lebesgue measurable.
